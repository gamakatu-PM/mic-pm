# KM 카카오 알림 v1.1 (2026-09-05)

구글시트·캘린더·드라이브에 흩어진 알림거리를 **카카오톡 「나와의 채팅」**으로 보내는 Apps Script입니다.
차장님 PC가 꺼져 있어도 구글 서버에서 돌아갑니다. 비용 0원, 사업자 채널·심사 불필요.

- **평일 = 짧게(오늘 볼 것만), 주말 = 넓게(전체 검토).** 주말 검토판은 D-day 밖 항목과 기한 없는 항목까지 모두 담고, 한 줄 60자로 길게 씁니다. 요일·시각·줄수는 설정 탭에서.
- 카카오 텍스트 메시지는 **한 건 200자**가 한도입니다. 넘치면 `(1/3) (2/3) …`로 자동 분할됩니다.
- 보낼 것이 하나도 없는 날은 `🟢 무조건할일·D-day·일정 없음` 한 건만 옵니다(살아 있다는 신호).
- 카카오 전송이 실패하면 같은 내용이 **Gmail**로 옵니다(설정에서 끌 수 있음).
- 무조건할일에 알림을 보낼 때마다 **J열 알림 횟수 · K열 마지막 알림일**을 갱신합니다(km-18 규격의 Claude 전용 열). B~I열은 건드리지 않습니다.

## 설치 (PC에서 약 15분, 한 번만)

### 1단계 — 카카오 개발자 콘솔 (developers.kakao.com)
1. 내 애플리케이션 → 기존 앱(작업거점 파인더에 쓰던 앱) 선택.
2. **앱 키 → REST API 키** 복사해 둔다.
3. **제품 설정 → 카카오 로그인 → 활성화 ON.**
4. 같은 화면 **동의항목 → 「카카오톡 메시지 전송(talk_message)」 → 선택 동의**로 설정.
   (앱 설정 → 앱 권한 신청이 아니라 **카카오 로그인 → 동의항목** 메뉴입니다. 메뉴 이름은 콘솔 개편에 따라 조금 다를 수 있음.)
5. Redirect URI는 3단계에서 웹앱 주소가 나온 뒤 등록합니다.
6. (선택) 보안 → Client Secret 을 켰다면 그 값도 복사. 안 켰으면 비워 둔다.

### 2단계 — Apps Script 프로젝트
1. https://script.google.com → **새 프로젝트** → 이름 「KM 카카오 알림」.
2. `Code.gs` 내용을 통째로 붙여넣기.
3. 프로젝트 설정(⚙) → **「appsscript.json 매니페스트 파일 표시」 체크** → 편집기에 나타난 `appsscript.json`을 이 폴더의 파일 내용으로 교체.
4. 함수 선택 → `setup` → ▶ 실행 → 권한 허용(시트·드라이브·캘린더·외부 접속·메일).
   → 드라이브 KM_블록작업 폴더에 **「KM 카카오 알림 설정」** 시트가 생기고, 트리거 3개가 설치됩니다.
5. 실행 로그에 찍힌 설정 시트 주소를 열어 **KAKAO_REST_KEY** 칸에 REST API 키를 넣는다.

### 3단계 — 웹앱 배포 (카카오 인증용)
1. 편집기 우상단 **배포 → 새 배포 → 유형: 웹 앱**
   - 실행 사용자: **나**
   - 액세스 권한: **모든 사용자** (인증 콜백을 카카오가 호출하므로)
2. 배포 후 나온 **웹 앱 URL(…/exec)** 복사.
3. 설정 시트 **WEBAPP_URL** 칸에 붙여넣기.
4. 카카오 콘솔 → 카카오 로그인 → **Redirect URI**에 같은 URL을 그대로 등록.

### 4단계 — 카카오 인증 (폰에서도 됨)
1. 웹 앱 URL을 브라우저에서 연다 → **「카카오 인증 시작」** 버튼 → 카카오 로그인 → 「카카오톡 메시지 전송」 동의.
2. 「연결 완료 ✅」가 뜨고 **카카오톡 나와의 채팅에 확인 메시지**가 오면 끝.
3. 편집기에서 `testSend` 실행으로 한 번 더 확인 가능.

토큰은 스크립트가 자동 갱신합니다(리프레시 토큰 유효 2개월, 만료 1개월 전부터 자동 재발급). 두 달 넘게 스크립트가 한 번도 안 돌면 재인증이 필요하며, 그때는 Gmail로 「카카오 인증 안 됨」 대체 메일이 옵니다 → 4단계만 다시.

### 「추가출처」 탭 — 역산표·대시보드 등 다른 시트의 D-day를 같이 보려면
| 출처 이름 | 시트 ID | 탭 이름 | 헤더 행 | 날짜 열 | 제목 열 | 현장 열 | 상태 열 | 완료로 볼 값 | 사용 |
|---|---|---|---|---|---|---|---|---|---|
| 현장 역산표 | (주소의 /d/ 뒤 문자열) | 탭 이름 그대로 | 1 | B | A | C | F | 완료 | **Y** |

- 날짜 열이 읽히는 형식: `260908` / `260908(예정)` / `2026-09-08` / `2026.9.8` / `9/8` / 시트 날짜 셀.
- 상태 열이 체크박스(TRUE)이거나 「완료로 볼 값」과 같으면 제외. 상태 열을 비우면 전부 미완료로 봄.
- 사용 = N이면 읽지 않음. 시트 ID가 틀리면 그 출처만 건너뛰고 발송로그에 X로 남음.

### 「발송로그」 탭
시각 · 종류 · O/X · 글자수 · 내용/오류. 3,000행 넘으면 앞 500행 자동 삭제.

## 편집기에서 손으로 누르는 함수
| 함수 | 용도 |
|---|---|
| `setup` | 최초 설치 (설정 시트 + 트리거) |
| `installTriggers` | 브리핑 시각 바꾼 뒤 트리거 재설치 (같은 이름 트리거는 전부 지우고 1개씩만) |
| `testSend` | 카카오 연결 확인 1건 |
| `previewMorning` / `previewEvening` / `previewWeekend` | **전송 없이** 내용만 실행 로그로 확인 |
| `previewHourly` | 신규 현장·시스템 검사 결과만 로그로 |
| `resetSeen` | 「이미 알린 것」 기록 초기화 (다시 전부 알림) |
| `resetKakaoAuth` | 토큰 삭제 → 4단계 재인증 |

## 알아둘 것 · 한계
- **200자**: 카카오 텍스트 템플릿 한도. 긴 브리핑은 여러 건으로 옵니다.
- **발송량**: 평일 아침 3 + 저녁 3 + 이상 시 몇 건. 주말 검토판은 5종이 분할되어 10건 안팎. 분할되면 더 늘어납니다. 「나에게 보내기」의 공식 일일 한도는 공개 문서에서 확인하지 못했습니다(친구에게 보내기는 한도 있음). 하루 30건을 넘기지 않게 「할 일 최대 줄수」로 조절하세요.
- **시간 트리거**는 지정 시각 ±15분 안에 실행됩니다(구글 사양).
- **다른 사람에게 보내기**는 이 판에 없습니다. 팀원에게도 보내려면 각자 카카오 로그인 동의가 필요한 「친구에게 보내기」 또는 유료 알림톡으로 확장해야 합니다.
- **자가진단 ★ 판정**은 「0.브리지 자가진단」 탭 최근 30행에서 `★` 글자를 찾는 방식입니다. 그 탭의 열 구조를 이 코드는 모릅니다 — 오탐·미탐이 나오면 알려 주세요.
