1. 오늘 무엇이 잘못되어 있었나 (전부 실제로 눌러 확인)

폰 크기 브라우저에서 화면을 실제로 클릭하는 시험을 돌려 찾은 것입니다. 추측이 아닙니다.

무엇이 잘못어떻게 드러났나고친 내용
시트에 갇힘열쇠 창이 열리면 아래 탭(여정·오늘·현장)이 눌리지 않음. 닫기는 창 맨 아래라 스크롤해야 보임모든 창 맨 위에 제목 + ✕ 닫기 를 고정
회의가 여정에 안 감회의에서 「외함 납품 9/23」 을 찍어도 여정 열쇠는 계속 「추정」. 프로님이 보시면 왜 반영이 안 되나 싶음회의 끝 → 일정·수량이 열쇠로 들어감. 이전 값은 prev 에 남김. 회의 끝 화면에 「열쇠 n개 갱신」 표시
돈이 여정에 안 감계산서·계약 완료를 눌러도 여정은 그대로돈 탭 완료 → 해당 열쇠 확정
쉼표가 줄을 깨뜨림「소판 부착 반입, 타공만」 처럼 값에 쉼표가 있으면 PC 48번이 칸을 잘못 나눔값 안의 쉼표·줄바꿈을 · 로 바꿔 보냄. 시험에서 5칸 유지 확인
의뢰서 건명 중복「건명 : 작업의뢰서(외함)」 로 나옴「건명 : CB외함 제작 · 납품」 으로
저장 실패가 조용함공유 저장소에 못 써도 프로님은 모름위쪽 배지가 저장 실패 — 폰에만 있음 으로 바뀜
「지나옴」 을 제가 단정확인하지 않은 단계를 지나왔다고 표시 (규칙 13 위반)「지나왔을 수 있음 · 빈칸 n」 으로 바꾸고, 프로님이 한 번에 확정하는 단추를 둠
진실이 두 곳공정 9단계와 열쇠가 따로 저장되어 서로 다른 값을 가리킴공정 표시를 열쇠에서 파생. 진실은 열쇠 하나. 단계를 누르면 그 열쇠가 열림

2. 최고가 아닌 이유 (남은 한계)

등급한계지금 무슨 일이 생기나언제 없애나
큼열쇠를 손으로 채움현장 200곳이면 7,600번. 프로님은 몇 개 채우다 그만두시게 됩니다v6.3
큼회사 대장과 끊김PC 도구가 이미 아는 것(의뢰서·수금·도면 접수)을 앱은 모릅니다. 같은 값을 두 번 넣게 됩니다v6.3
중간언제까지인지 없음열쇠에 마감이 없어 「늦었다」 를 앱이 못 알려 줍니다. 속판은 2달이라 늦으면 못 되돌립니다v6.4
중간열쇠 문장이 코드 안「어떻게·왜」 가 틀려도 프로님이 앱에서 못 고치십니다. 제게 말씀하셔야 합니다v6.5
작음마이크·메일 열기 미검증아티팩트 화면 안에서 마이크 권한·메일 앱 열기가 막힐 수 있습니다. 막히면 「복사만」 으로 우회프로님이 한 번 눌러 보시면 즉시 판명

3. 판 5개 — 무엇을 · 누가 · 어떻게 확인

v6.3열쇠가 저절로 채워진다가장 먼저
손 7,600번을 없애는 판. 회사 대장이 이미 아는 것은 제가 넣고, 프로님은 상대가 말해 준 것만 누르십니다.
무엇을
열쇠 38개 중 13개를 자동으로 채웁니다(아래 표). 나머지 25개는 사람이 말해야 아는 것이라 그대로 둡니다.
프로님 손
0. 아침에 여정을 열면 이미 채워져 있습니다.
제 일
아침 한 장·의뢰서 대장·수금 대장·도면 접수·견적 발송을 읽어 열쇠에 넣습니다. 제가 넣은 것은 추정·진행중 이고 근거에 「도구 n번」 을 적습니다. 확정은 프로님만.
확인 방법
여정을 열었을 때 연합기숙사 열쇠가 1개가 아니라 10개 이상 채워져 있으면 된 것입니다.
위험
PC 도구가 내보내는 값과 열쇠 이름을 맞춰야 합니다. 틀리면 엉뚱한 열쇠가 채워지므로, 제가 넣은 것은 전부 「제 판독」 으로 표시해 되돌릴 수 있게 합니다.
v6.4언제까지 해야 하는가
속판 2달, 외함 2주, 기구물 1.5~2달. 늦으면 못 되돌리는 것을 앱이 먼저 말해야 합니다.
무엇을
의뢰서 열쇠 8개에 발행 마감일을 붙입니다. 준공일 또는 벽지 예정일에서 거꾸로 계산합니다. 여정 카드에 「속판 의뢰서 D-12」 가 뜨고, 지났으면 빨강.
프로님 손
현장당 1번 — 준공일(또는 벽지 예정일) 입력. 이미 아시는 현장은 회의에서 찍힌 값으로 자동.
제 일
역산 규칙을 넣습니다. 시운전 7일 → 설치 7일 → 빽커버 10일 → 벽지 완료 → 기구물 제작 1.5~2달. 외함·속판은 현장 공법이 정하므로 역산하지 않고 상대가 말한 날만 씁니다.
확인 방법
준공일을 넣으면 의뢰서 열쇠에 D-day 가 뜨고, 그 값이 프로님 머릿속 계산과 맞는지 한 현장만 보시면 됩니다.
위험
소요일이 현장마다 다릅니다. 현장별로 고칠 수 있는 칸을 둡니다. 제가 정하지 않습니다.
v6.5열쇠를 프로님이 고친다
「어떻게·왜」 문장은 지금 제가 쓴 것입니다. 현장을 아시는 분은 프로님입니다.
무엇을
열쇠마다 「이 설명 고치기」. 고치신 문장이 모든 현장에 적용되고 저도 그것을 읽습니다. 현장 하나만 다르면 그 현장에만 두는 선택도 둡니다.
프로님 손
틀린 줄에서 1번. 말씀으로 고치셔도 됩니다(🎙).
제 일
고치신 문장을 스킬(km-35)과 인수인계에 이중 저장합니다. 새 창도 같은 문장을 씁니다.
확인 방법
한 줄 고치고 다른 현장 같은 열쇠를 열었을 때 그 문장이 보이면 된 것입니다.
v6.6검수 · 시운전답 필요
수금의 마지막 근거. 지금 시운전을 무엇으로 확인하시는지 몰라 뒤로 뺐습니다.
무엇을
객실 번호 격자에 품목별 O/X. X는 사진 한 장 + 한 줄 → 하자 목록 → 시공팀 AS 의뢰서 초안 → 사진대지(8번)로.
프로님 손
객실당 1탭. 200실이면 200탭이지만 이동 중이 아니라 현장에서 하시는 일이라 대체가 없습니다.
제 일
시운전 100%가 되면 「계산서 요청 문안 만들까요?」 를 먼저 내밉니다.
먼저 여쭐 것
지금은 무엇으로 확인하십니까? 종이 체크표 / 사진만 / 시공팀이 따로 / 머리로. 답에 따라 격자 모양이 달라집니다.
v7.0메일 없이 저와 바로 주고받기
지금은 「보내기」 가 메일을 한 통 띄웁니다. 그 단계도 없앨 수 있습니다.
무엇을
앱에 쌓인 줄을 제가 공유 저장소에서 바로 읽습니다. 프로님은 보내기를 누르지 않아도 됩니다. 제가 처리한 줄은 앱에 「반영했습니다 · 무엇을」 로 되돌아옵니다.
프로님 손
0. 단추만 누르시면 끝.
제 일
새 창을 열 때 저장소의 미처리 줄부터 읽고, 확정 대장·서류에 반영한 뒤 앱에 표시를 되돌립니다.
남는 것
PC 도구(48번)로 보내는 메일은 그대로 둡니다. 없애지 않습니다. 두 길이 같은 대장을 봅니다.

5. 순서와 이유

  1. v6.3 자동 채움 — 이것이 안 되면 나머지가 소용없습니다. 열쇠가 비어 있으면 아무도 안 씁니다.
  2. v6.4 D-day — 채워진 열쇠에 마감이 붙어야 「지금 무엇을」 이 나옵니다.
  3. v6.5 문장 고치기 — 프로님이 쓰실수록 틀린 문장이 드러납니다. 그때 고칠 길이 있어야 합니다.
  4. v6.6 검수 — 현장에서 쓰는 화면이라 앞의 셋과 성격이 다릅니다. 답을 받은 뒤에.
  5. v7.0 직접 주고받기 — 앞이 다 돌아간 뒤 마지막 손 1번을 없앱니다.
