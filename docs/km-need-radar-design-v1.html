「지금 필요한 것」 레이더 — 설계안

저장 위치: GitHub mic-pm 저장소 `docs/` (이 파일) + 대화창. 구글 드라이브·노션에는 올리지 않음.
결론: 현장마다 「공정단계 × 기록 상태 × 날짜」에서 지금 필요한 문서·행위를 규칙표로 뽑아, ①아침 ②현장 열 때 ③기록 저장 직후 세 시점에 한 줄씩 추천한다. 규칙표는 앱(JSON)과 스킬(md)에 이중 저장해 새 창도 같은 기준으로 추천한다.

지금 앱(현장관리 v5.7)은 「일어난 일」(이슈·기한초과·미수금)만 경고한다. 「다음에 뭐가 필요한가」(외함 의뢰서 낼 때인가, 벽지 완료일을 물어야 하나, 계산서 2회차인가)는 차장님 머리에만 있다. 이 설계는 그 머리를 규칙표로 꺼내 앱이 대신 세게 만드는 것이다.

1. 대안 3개 — 어디서 추천이 나오는가

A안 (권장)
앱 안의 규칙 엔진
현장관리 웹앱에 「지금 필요한 것」 화면을 넣고, 앱이 가진 데이터(단계·이슈·의뢰서·계산서·마지막 기록일)만으로 규칙표를 돌린다. Claude 없이도, 오프라인에서도 돈다. 규칙표는 스킬에도 같이 저장.
잃는 것: 통화·회의의 뉘앙스는 못 읽는다. 규칙표에 없는 상황은 못 잡는다(그건 차장님이 규칙을 한 줄 추가해야 잡힌다).
B안
아침 스케줄이 Claude 판단으로 추천
평일 07:30 「KM 정본 아침 작업」이 26년 회의록 시트·정본 대시보드를 읽고 현장별 추천 3줄을 푸시. 통화 내용까지 반영된다.
잃는 것: 하루 1회다. 낮에 상황이 바뀌면 다음 날 아침까지 모른다. Claude 판단이라 매 줄에 근거 태그가 붙어야 하고, 규칙표가 없으면 아침마다 기준이 흔들린다.
C안
대화창 답변 끝 추천만 강화
km-00-router에 규칙표를 붙여, 세션에서 현장이 언급되면 그 현장 단계의 「필요한 것」을 답변 끝 추천 명령문으로 낸다. 앱 수정 없음.
잃는 것: 대화를 열어야만 나온다. 말 안 꺼낸 조용한 현장은 영영 안 뜬다. 200개 현장을 다 대화로 훑을 수 없다.

A안이 뼈대이고 B·C는 A의 규칙표를 그대로 쓰는 배달 통로다. A를 먼저 만들면 B·C는 규칙표 재사용이라 추가 비용이 작다. 반대로 B·C만 만들면 규칙표가 Claude 기억에만 남아 새 창마다 흔들린다.

3. 규칙표 — 이것이 엔진의 전부다

각 규칙은 「어느 단계에서 · 무엇이 있으면/없으면 · 무엇이 필요하다 · 한 줄 추천 · 눌러서 할 것」 다섯 칸이다. 노란칸은 차장님이 숫자를 넣는 소요일이고, Claude가 정하지 않는다(km-site-schedule 확정값을 출발값으로).

5. 차장님이 손댈 곳 vs 자동

손댈 곳 (노란칸)
  • 소요일 9칸 — 출발값은 km-site-schedule 확정값. 현장마다 고칠 수 있음
  • 준공일 · 벽지/페인트 완료 예정일 · 외함 납품 예정일 (현장이 정하는 값)
  • 단계 넘김 · 착수확인 · 계산서 기록 버튼
  • 규칙 켜기/끄기 · 새 규칙 한 줄 추가 (트리거·필요한 것·추천문)
자동
  • 역산 날짜 계산, D-day, 색 판정(🔴🟡🟢), 정렬(빨강 → 마감 임박 순)
  • 규칙 근거 표시 — 모든 카드에 「규칙 번호 + 어떤 데이터 때문에」
  • 버튼 → 기존 기능 호출(작업의뢰서 초안 genWO, 카톡 초안, 문서 탭 이동)
  • 규칙표를 스킬 md로 내보내기 (이중 저장, 새 창이 같은 기준 사용)

6. 못 하는 것 · 모르는 것

  • 한비로 결재 상태를 못 읽는다. 「착수확인」 버튼으로 우회한다(km-map 끊긴 고리 1). 차장님이 안 누르면 X2가 계속 뜬다.
  • 통화 내용은 앱이 모른다. PLAUD → 26년 회의록 시트 트랙은 별도다. 통화에서 나온 변경은 B안(아침 Claude)이 시트를 읽어야 반영된다. 1차에는 없다.
  • 규칙표에 없는 상황은 못 잡는다. 예: 발주처가 갑자기 성급을 올려 BSP로 바꾸는 경우. 이건 회의록 X1에서 사람이 잡는다.
  • 현재 앱 데이터에 없는 칸 3개: 준공일, 벽지 완료 예정일, 의뢰서 착수확인. 1차에서 현장 갑지에 추가해야 S1·S4·X2가 돈다.
  • 불확실한 것: 「조용한 현장」 기준 21일과 착수확인 7일은 Claude가 임시로 넣은 값이다. 노란칸으로 두고 차장님이 정한다.
