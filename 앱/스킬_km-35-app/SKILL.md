## 여정 = 9단계 × 열쇠 41개 (`config/quests`, 코드 기본값은 `20-quests.js` DEFAULT_QUESTS)
설계·도면납품 / 견적·계약 / CB외함 제작·납품 / 외함 설치(전기·통신) / 속판 제작·설치 / 강전·약전 결선·커버 / 기구물 제작 / 빽커버·기구물 설치 / 시운전·수금.
- 열쇠 type : fact(확정값) · doc(서류·의뢰서, `order`=부서) · ext(상대 행동) · work(우리 일). `gate:true` = 계약·계산서 확인.
- 열쇠 상태 4 : 미확정 / 추정 / 진행중 / **확정(프로님만)**. 제가 넣는 것은 추정·진행중 + `from`·`basis` 에 출처.
- **위치** = 활동 있는 첫 미완 단계. **다음 한 수** = 그 단계의 첫 빈 열쇠.
- **★ 계약·계산서 게이트** : 외함·속판·기구물 의뢰서 앞. 게이트 미확정이면 의뢰서 열쇠에 🔒 + 계약·계산서 요청 문안(`moneyDraft`). 프로님 규칙 「물건 만들기 전 계산서·계약 요청」.
- **마감 역산** (`deadlines`) : 준공 −7 시운전 → −7 설치 → −10 빽커버 → 벽지 → −50 기구물 의뢰서(계약은 −3 더) / 외함 납품 −14 / 속판 납품 −60(없으면 준공 −7 −강전 30). 현장별 소요일 `s.lead` 가 기본 `LEAD` 를 덮는다. 열쇠에 D-n · 오늘 화면 「늦으면 안 되는 것」. **확정된 열쇠는 재촉하지 않는다.**
- 공정 9단계 표시는 열쇠에서 **파생**(진실은 열쇠 하나).

## 연동 (양방향 4고리)
1. 데이터 → 앱 : PC 49번(`t49_appfeed.py`)이 회의록 원문·대장을 읽어 JSON → 클립보드 → 앱 설정 「PC에서 붙여넣기」(`takeFeed`). 또는 제가 레포에서 읽어 `ArtifactData` 로 씀(`feed.py`·`feed2.py`). 앱은 보안상 외부 주소를 직접 못 읽는다.
2. 앱 → 프로님 : 여정 띠 「제가 채운 것 n건」(맞아/아니야) · 「제가 반영했습니다」(inbox).
3. 앱 → 클로드 : `meta/outbox`·`asks(who 프로님)`·`decisions`. **새 창 첫 동작으로 읽는다.**
4. 앱 → PC 대장 : 「보내기」 메일(`[KM] 회신`) → PC 50번이 확정사항·전화번호부·경계·하자 csv 에 append. 확정만.
- 회의록을 제가 직접 읽는 것은 PC 정리본 기준 회의 1건 ≈ 370토큰(PLAUD 원본은 1만). 파이썬이 훑고 숫자·변경이 걸린 것만 저에게.

## 새 창이 할 일 (순서)
1. `ArtifactData list meta` → `outbox.lines` 처리 → `meta/inbox` 에 한 줄.
2. `list asks` → `who:'프로님'` 열림 = 프로님 질문. 답하고 `answer/status/answeredAt`.
3. `list decisions` 최근 → 확정 대장으로 필요한 것 반영. **뒤집지 않는다.**
4. 새 자료가 있으면 `feed2.py` 방식으로 `sites/items` 에 넣되 **기존 문서는 list 로 버전을 읽어 `if_version`**. 채운 것은 `from` 붙여 추정·진행중으로.
5. 열쇠 문장·목록을 고쳐 달라 하시면 **코드가 아니라 `config/quests`** (ver+1, bak 함께).
