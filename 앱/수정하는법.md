## 고치는 순서 (이것만 지키면 안 깨진다)
1. **그 파일만** 연다. 다른 파일은 열지 않는다.
2. 고친다.
3. `node 앱/KM손바닥_자가시험.mjs` (25개) 와 `node 앱/KM손바닥_극단시험.mjs` (10개) 를 돌린다 → **35개 전부 통과**여야 한다. 2호도 같은 시험에 경로만 `v2/index.html` 로 준다.
4. 통과하면 그 파일 하나만 다시 올린다 (Artifact publish, `url` 은 항상 같은 주소, `files` 에 바꾼 파일만).
5. 실패하면 **고친 것을 되돌리고** 원인을 찾는다. 통과 못 한 판은 올리지 않는다.

## 파일이 갈려서 생기는 함정 (겪은 것)
- 다른 파일의 함수를 **즉시** 참조하면 깨진다. `onclick=sendOutbox` → `onclick=()=>sendOutbox()` 로 미룬다.
- 최상위 `let/const` 는 **번호 순서**대로 만들어진다. `20-quests.js` 의 `QUESTS` 를 `10-core.js` 에서 바로 쓰면 없다. 함수 안에서 쓰는 것은 괜찮다.
- 그래서 파일 이름의 번호가 곧 실행 순서다. 새 파일을 넣을 때 번호를 잘 고른다.

### 접기(3호)를 고칠 때 — `14-fold.js` 한 파일
| 고쳐 달라는 말 | 고칠 곳 |
|---|---|
| 「더 접어라 / 덜 접어라」 | `km.css` 의 `--foldh` (58 / big 68 / big2 78px) |
| 「이건 접지 마라」 | `14-fold.js` 의 `NOFOLD` · `foldSkip()` |
| 「이것도 접어라」 | `14-fold.js` 의 `FOLD_SEL` |
| 「단추 글자를 바꿔라」 | `14-fold.js` 의 `foldSet()` |

**함정 (겪은 것)**
- 카드마다 높이를 재면 현장 200곳에서 멈춥니다. `applyFold()` 는 **① 감싸기 ② 한 번에 재기 ③ 접기** 세 단계로 갈라 놓았습니다. 이 순서를 섞지 마십시오.
- 제목(`.id`/`.t`/`.q`)은 접기 밖에 둡니다. 안에 넣으면 제목이 반으로 잘립니다.
- `.jcard` 는 카드 자체에 `onclick` 이 있어 접지 않습니다. 접으면 현장 여는 것과 부딪힙니다.
- 화면을 바꾸면 이전 화면의 「전부 펴기」 띠가 남습니다. `foldBar()` 가 치웁니다.
