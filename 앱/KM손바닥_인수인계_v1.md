## 공유 저장소 (클로드 ↔ 앱 양방향의 실제 통로)
아티팩트 `db` 기능. **클로드는 `ArtifactData` 도구로 읽고 쓴다** (url = 위 앱 주소).
| 컬렉션/문서 | 내용 | 클로드가 하는 일 |
|---|---|---|
| `items/{id}` | 오늘 화면 줄. `kind`: ask(답해 주십시오)/todo(오늘 할 것·확정)/make(제가 만들까요). `status`: open/progress/done/confirmed/cancel/requested. `fix`=프로님이 「아니야」 로 고친 값. `history[]` | 아침 한 장을 여기에 넣는다(id 는 KM-### 그대로, 없으면 A-/P-/M- + hash). **프로님이 바꾼 status·fix 를 읽어 확정 대장에 반영** |
| `sites/{s_hash}` | 현장. `stages{key:{date,note}}`=프로님이 누른 확정 공정, `facts[]`=확정값(43번), `people[]`, `money{}`, `bound{}` | 확정 표를 facts 로 넣는다. stages 는 프로님만 |
| `meetings/{m_ts}` | 회의. changes/sched/bound/notes, ended | 끝난 회의 → 증감·의뢰서 초안 검토 |
| `meta/outbox` | 아직 PC 로 안 보낸 한 줄들 `{lines:[{ts,line,site,type}]}` | **새 창 시작 때 읽어 「받은답」 으로 처리하고 GitHub 커밋 → 98번** |
| `meta/log` | 최근 600줄 이력 | 읽기만 |
| `meta/settings` | mailTo(기본 gamakatu0924@gmail.com), cc, big | 손대지 않음 |
