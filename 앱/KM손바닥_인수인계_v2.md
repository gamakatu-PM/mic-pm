# KM 손바닥 v6.1 「여정판」 — 새 창 인수인계 v2 (2026-09-19)

v1(`KM손바닥_인수인계_v1.md`) 위에 얹는다. v1 의 저장소 구조·한 줄 문법·새 창 할 일은 그대로 유효.

## 프로님 지시 (원문 요지, 2026-09-19)
"이건 매일 오는 거하고 똑같잖아. 앱은 좀 재밌게. 공정표의 단계를 클릭하면 **무엇이 필요하고 지금 상태가 어떤지** 네가 알려주고, 내가 알려준 정보로 네가 완성해 가는 것. 속판을 만들려면 뭐가 아직 확정이 안 됐고 협의해서 확정하라고 알려주는 식."
→ 홈을 「여정」 으로 바꿨다. 오늘 화면은 두 번째 탭으로 남김(없앤 것 없음).

## 여정 구조 (QUESTS · 코드 안 정본)
9단계 × 열쇠(필요한 것) 38개. 단계 = 설계·도면납품 / 견적·계약 / CB외함 제작·납품 / 외함 설치(전기·통신) / 속판 제작·설치 / 강전·약전 결선·커버 / 기구물 제작 / 빽커버·기구물 설치 / 시운전·수금.
열쇠마다 : 이름 · type(fact 확정값 / doc 서류·의뢰서 / ext 상대 행동 / work 우리 행동) · 누가 · 어떻게 확정하나 · 왜 필요한가 · (doc 는 order = 의뢰 부서).
- 열쇠 상태 4가지 : 미확정 / 추정 / 진행중 / 확정. **프로님이 누른 것만 확정.** 클로드가 넣은 것은 추정·진행중 + 근거에 「클로드 판독」.
- 위치(현재 단계) = 활동이 있는 첫 미완 단계. 지나온 단계의 빈칸은 「지나옴 · 빈칸 n」 으로 보이고 「이 단계는 이미 지났음」 단추로 프로님이 일괄 확정.
- 다음 한 수 = 현재 단계의 첫 빈 열쇠. 단추 : 열기 / 「제가 ○○ 만들까요?」(type 별 문안·의뢰서 초안) / 전화 첫마디 / 🎙 들은 대로.
- 열쇠 확정 중 일부는 공정 9단계(stages)와 연동 : 외함납품·속판납품·기구물납품·벽지완료·빽커버·설치완료·커버·시운전완료.

## 저장 (v1 구조에 추가)

씨앗(2026-09-19, 클로드 판독) : 연합기숙사 6열쇠(계약형태 확정 / 계약완료·타공도·기구물수량 진행중 / 외함납기·외함공법 추정) · 양양쏠비치 3열쇠(등급객실·강전일정 추정 / 수량표 진행중). 근거는 각 열쇠 basis.
