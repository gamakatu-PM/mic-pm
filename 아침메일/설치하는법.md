# KM 아침메일 — 구글이 보내게 만들기 (v1, 2026-09-21)

## 왜 이걸 합니까

9/18 이후 아침 메일이 한 통도 안 갔습니다. 원인은 스케줄러가 아니라 **보내던 것이 사람(클로드)이었기 때문**입니다.
메일 원본 머리글을 보면 9/18 5통은 전부 구글 API 로 나갔고, **파이썬이 SMTP 로 보낸 흔적은 한 통도 없습니다.**

그래서 역할을 이렇게 나눕니다.

| 누가 | 무엇을 | 언제 |
|---|---|---|
| **PC 파이썬** | `_아침한장.md` 를 읽어 메일 3통을 만들어 **올려만 둔다** | PC 켜질 때 + 3시간마다 |
| **구글(앱스 스크립트)** | 올라온 것을 **보낸다** | **매일 07:00 (PC 꺼져 있어도)** |
| 클로드 | 손대지 않는다 | — |

자료가 낡으면 제목에 「자료는 어제 것입니다 / ⚠ n일 지났습니다」가 붙습니다. **모르고 믿는 일이 없게** 하려는 것입니다.

---

## 1단계 — 파일 두기 (2분)

`아침메일` 폴더째로 KM 도구 옆에 둡니다. 예 : `...\2_KM도구\아침메일\`

```
아침메일\
  km_morning_push.py     ← PC 가 자료를 만들어 올리는 것
  아침메일_설정.ini       ← 주소·암호 적는 곳
  아침메일_보내기.bat     ← 손으로 한 번 돌릴 때
  예약등록.bat            ← 처음 한 번만 (자동 등록)
  _조용히올리기.bat       ← 예약이 부르는 것 (직접 안 누름)
  KM_아침메일_웹앱.gs     ← 구글에 붙여넣을 것
```

## 2단계 — 구글 쪽 만들기 (5분)

1. script.google.com → **새 프로젝트** → 이름 `KM 아침메일`
2. `KM_아침메일_웹앱.gs` 내용을 **통째로 붙여넣기**
3. 맨 위 `설정` 의 **암호**를 아무 말이나로 바꿉니다. 예 : `km-bsy-0921`
4. 왼쪽 ⚙ **프로젝트 설정 → 시간대를 (GMT+09:00) Seoul** 로 맞춥니다 ← **이걸 빼먹으면 07:00 이 어긋납니다**
5. 오른쪽 위 **배포 → 새 배포 → 유형 「웹 앱」**
   - 실행 : **나(gamakatu0924)**
   - 접근 권한 : **모든 사용자**
   - 배포 → 권한 허용 → 나온 **주소(.../exec)를 복사**
6. 함수 목록에서 **`설치`** 를 한 번 실행합니다 → 매일 07:00 트리거가 걸립니다

## 3단계 — PC 쪽 이어 주기 (2분)

`아침메일_설정.ini` 를 메모장으로 열어 두 줄만 채웁니다.

```ini
[웹앱]
url = (5번에서 복사한 주소)
secret = (3번에서 정한 암호 — 글자 하나까지 똑같이)
```

## 4단계 — 시험 (3분)

1. `아침메일_보내기.bat` 더블클릭 → `구글 답 : {"ok":true ...}` 가 나오면 성공
   - `_아침한장.md 를 못 찾았습니다` → 36번(★KM_도면넣고_여기클릭)을 한 번 누르고 다시
2. 앱스 스크립트에서 **`시험발송`** 실행 → bsy 메일함 확인
3. 같은 것을 또 받아 보고 싶으면 **`오늘다시`** → **`시험발송`**

## 5단계 — 자동으로 (1분)

`예약등록.bat` 을 **한 번** 더블클릭합니다. (로그인할 때 + 3시간마다 자동으로 올라갑니다)

---

## 이렇게 됩니다

- **매일 07:00** — 구글이 ① 답해 주십시오 / ② 오늘 할 것 / ③ 어제 회의록 세 통을 bsy 로 보냅니다. PC 가 꺼져 있어도 옵니다.
- **회의록을 늦게 넣으신 날** — `아침메일_보내기.bat --now` 를 누르면 ③번만 그때 한 번 더 옵니다.
- **같은 날 같은 편은 두 번 가지 않습니다** (구글이 기록해 둡니다)
- **PC 를 며칠 안 켜셨으면** — 제목에 ⚠ 로 며칠 지난 자료인지 적혀서 옵니다.

## 안 되면 여기부터

| 증상 | 볼 곳 |
|---|---|
| 메일이 아예 안 옴 | 앱스 스크립트 **`상태보기`** 실행 → 트리거·시간대·자료기준 |
| 「PC 자료가 없습니다」 메일이 옴 | PC 에서 `아침메일_보내기.bat` 한 번 |
| 07:00 이 아닌 때 옴 | 2단계 4번 **시간대 Seoul** |
| `암호가 다릅니다` | ini 의 secret 과 gs 의 설정.암호 |
| 올라갔는데 메일이 안 옴 | 드라이브 KM_블록작업 폴더의 `km_morning_log.csv` |

## 손대지 않은 것

- 기존 KM 도구(t35·36번·42번)는 **한 줄도 고치지 않았습니다.** 이 폴더는 옆에 얹는 것입니다.
- 회의록 본문·금액·수량은 `_아침한장.md` 에 있는 것만 옮깁니다. **새로 지어내지 않습니다.**
