🔑 카카오 지도 키 설정 (최초 1회, 무료)

지도와 실시간 장소검색(폐업 반영)을 쓰려면 카카오 개발자 키가 필요합니다. 발급은 무료이고 5분이면 됩니다. 계정당 첫 번째 카카오맵 앱은 무료 쿼터가 제공되어 개인용으로는 비용이 들지 않습니다.

1
developers.kakao.com 접속 → 카카오 계정으로 로그인
2
[내 애플리케이션] → [애플리케이션 추가하기] → 앱 이름 아무거나(예: 작업거점) 입력해 생성
3
만든 앱에서 [앱 키] 항목의 JavaScript 키를 복사. 같은 화면(또는 [플랫폼] 메뉴)에서 Web 사이트 도메인에 https://gamakatu-pm.github.io 를 등록
4
[제품 설정] → 카카오맵 사용 설정을 활성화 (메뉴 위치는 개편으로 다를 수 있으나 "카카오맵" 활성화 스위치를 켜면 됩니다)
5
복사한 JavaScript 키를 아래에 붙여넣기 → 저장
지도를 불러오는 중…
카테고리를 누르면 지도 중심 기준으로 검색합니다. 한번 등록한 거점은 ✅로 표시됩니다.
아직 등록된 거점이 없습니다. 🔍 찾기에서 장소를 검색해 「거점 등록」을 누르거나, 이미 아는 곳은 「＋ 직접 추가」로 넣어 두세요. 한번 검증해 두면 다음부터는 검색 없이 여기서 바로 고르면 됩니다.

🔑 카카오 JavaScript 키

지도가 안 뜨면: ① 키가 JavaScript 키인지(REST 키 아님) ② 카카오 개발자 앱의 Web 도메인에 https://gamakatu-pm.github.io 등록 ③ [카카오맵] 활성화 — 세 가지를 확인하세요.

🅿️ 무료·공영 주차장 데이터 (선택, 강력 추천)

공공데이터포털의 전국주차장정보표준데이터 CSV를 한 번 넣어두면, 검색 결과 카드마다 가장 가까운 무료·공영 주차장과 거리가 자동 표시되고 「무료주차 도보5분」 필터를 쓸 수 있습니다.

  1. data.go.kr 접속 → "전국주차장정보표준데이터" 검색 (데이터셋 번호 15012896)
  2. CSV 다운로드 (로그인 없이 가능)
  3. 아래 버튼으로 그 CSV 파일 선택 → 서울·경기의 무료/공영 주차장만 자동 추출해 저장합니다

데이터가 없어도 🅿️ 주차장 버튼으로 카카오 실시간 주차장 검색은 가능합니다 (무료 여부는 카카오맵 상세에서 확인).

💾 내 거점 백업

거점 데이터는 이 브라우저(localStorage)에 저장됩니다. 기기를 바꾸거나 브라우저 데이터를 지우기 전에 내보내 두세요.

ℹ️ 사용 팁

· 폐업/영업시간/리뷰는 카드의 「카카오맵」 버튼에서 최신 정보로 확인됩니다 — 블로그 검색과 달리 죽은 정보가 없습니다.
· 현장 동선별로 고정 거점 2~3곳(공영주차장 붙은 도서관 + 스터디카페 1곳)을 등록해 두는 것이 가장 효율적입니다.
· 홈 화면에 추가(브라우저 메뉴 → 홈 화면에 추가)하면 앱처럼 쓸 수 있습니다.
