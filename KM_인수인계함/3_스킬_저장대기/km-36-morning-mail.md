# km-36 아침 메일 (v1 · 2026-09-21)

## 0. 새 창이 가장 먼저 알아야 할 것

**아침 메일을 클로드가 보내면 안 된다.** 2026-09-18 에 클로드가 손으로 5통을 보냈고,
그 창이 닫힌 9/19부터 **메일이 한 통도 안 갔다**. 사람 손에 물려 있으면 반드시 끊긴다.

## 1. 2026-09-21 확인된 사실 (추측 아님, 메일 원본 머리글로 확인)

| 무엇 | 사실 |
|---|---|
| 9/18 아침 5통 | `by gmailapi.google.com with HTTPREST` = **클로드의 Gmail 도구**가 보낸 것 |
| 파이썬 t35 (SMTP) | 보낸 흔적 **한 통도 없음**. 즉 한 번도 동작한 적 없다 |
| 「신규 현장 레이더」 | 앱스 스크립트. 매일 06:40 정상 도착 → **구글에서 보내는 길은 살아 있다** |
| 26년 회의록 앱스 스크립트 | 9/12 중지 결정했는데 **아직 살아서 10분마다 `km_snapshot.json` 을 쓰고 있다**(9/21 16:09 확인) → 정리 대상 |

## 2. 확정 구조 (2026-09-21)

```
PC 파이썬            →   드라이브(km_morning.json)   →   구글 앱스 스크립트   →   bsy@micronic.co.kr
km_morning_push.py       KM_블록작업 폴더                매일 07:00 발송
(PC 켜질 때·3시간마다)                                   (PC 꺼져 있어도 감)
```

- **만드는 것은 PC, 보내는 것은 구글.** 클로드는 둘 다 하지 않는다.
- 자료는 `_아침한장.md` 의 `## 절` 을 그대로 옮긴다. **새로 지어내지 않는다.**
- 편성 : ① = 제가 만들까요?·답을 못 받아 진행하지 않은 것·못 알아들은 답 / ② = 앞으로 해야 될 것·찾아갈 곳 / ③ = 미확인 회의록
- 자료가 낡으면 **제목에** 「자료는 어제 것입니다 / ⚠ n일 지났습니다」가 붙는다.
- 같은 날 같은 편은 두 번 가지 않는다(앱스 스크립트 PropertiesService 기록).
- 회의록을 늦게 넣으신 날은 `아침메일_보내기.bat --now` → ③번만 그때 한 번 더.
