# 매일 오는 메일 두 개 정리 (v1, 2026-09-19)

새 창이 이 파일을 먼저 읽고, 아래 결정을 뒤집지 말 것. (km-00 18번 = 스킬 + 인수인계함 이중 저장)

## 프로님 말씀 (2026-09-19, 그대로)

> "첨부 사진은 메일로 오는 두 가지인데 이 2개가 참 아이러니해.
>  ① 매일 0건 오는 거 — 내가 산군을 하면서 필요가 없어졌거든. 조사인데 건수가 0이야.
>     산군에서 조회된 현장을 조사해서 나한테 알려 주는 걸로 하면, 클로드가 하는 게 아니라
>     코드가 짜서 PC에서 하면 사용량이 들지 않지 않을까.
>  ② 두 번째 이건 올가닉(분석실패) 항목을 나한테 메일로 보내지 말고, 관점을 바꿔서
>     현장 조사한 거, 그거를 제대로 보내 줬으면 좋겠어. 중복 체크는 내가 하지."

## 이번에 만든 것 세 개

### 1. PC 도구 49번 `t49_sangun.py` — 산군 파일 → 새 현장 (토큰 0)
- 산군 > 관심현장 > 엑셀 내려받기(주 1회 최대 300건) → 49번 실행 → 엔터
- 다운로드 폴더에서 최근 산군 파일을 스스로 찾음. xlsx·csv 둘 다 읽음. 열 이름이 달라도 낱말로 찾음
- 하는 일 : **중복 제거**(`_도구결과\_대장\산군_처리.csv` 에 한 번 본 현장을 기록) → **판정** → **갈 곳(설계사)** 까지
- 판정 기준은 `설정.ini [산군]` 에 숫자로 빠져 있음 (숙박 1500 / 단독 496 / 클럽하우스 1000 / 그 밖 500 / 착공최근개월 6).
  **요율·수치는 도구가 정하지 않는다(규칙 19)** — 프로님이 숫자만 고치시면 됨
- 판정 규칙 : ★ = 기준의 2배 이상(대형) + 지금 들어갈 때(착공 6개월 이내 또는 착공 전) / △ = 기준은 넘음 / ✕ = 객실 용도 아님·규모 미달·허가 3년 넘도록 착공 없음
- **정답본 대조 통과** : 프로님이 손으로 만드신 「산군_관심현장 v1 (2026-09-14, 11건)」 의 판정과 **11건 전부 일치**
- 산출물 : `_도구결과\산군\산군_새현장_YYMMDD.xlsx / .csv / .html`(한 장, 자동으로 뜸)
- 조사(발주처·객실수 확인)는 **이 도구가 하지 않음**. ★ 줄만 클로드에게 주시면 조사함 (그래야 토큰이 안 든다)
- 메뉴에 넣으려면 `menu.py` 의 '총괄' 그룹 마지막 줄 뒤에 한 줄 추가 :
  `('산군 관심현장 정리  산군에서 받은 파일 → 새 현장만 판정·중복제거 (토큰 0)', 't49_sangun')`

### 2. `레이더_메일_v8.gs` — 0건 메일 중지 (구글시트 「신규 현장 레이더」)
- 확정 0건 · 재검토 0건이면 **메일을 보내지 않음**
- 조용히 죽는 걸 막으려고 : 0건이 이어지면 날수를 세고 **7일째 되는 날 한 번만** 「7일째 0건 — 살아는 있는지」 점검 메일. 건수가 하나라도 나오면 날수는 0으로
- 레이더 자체(수집·검색·시트 기록)는 **끄지 않았음**. 메일만 줄였음 (km-00 36번 = 시키지 않은 중지 금지)
- 붙이는 법 : 시트 > 확장 프로그램 > Apps Script > 기존 레이더 파일 전체를 이 v8 내용으로 교체.
  `GEMINI_API_KEY` 는 기존 값을 그대로 다시 넣어야 함(파일에는 안 들어 있음)
- `GEMINI_MODEL` 은 `gemini-3.1-flash-lite` 그대로 — **pro·pro-preview·"-lite" 없는 flash 로 되돌리지 말 것**(9/1 사고)

### 3. `뉴스모니터링_현장만_메일_v1.gs` — 실패 목록 대신 현장만 (구글시트 「호텔신축_뉴스모니터링」)
- 「공사」 탭(발주처·시공사·기사제목 열이 있는 탭)을 스스로 찾아 **아직 안 보낸 줄만** 현장 카드로 보냄
- 카드에 들어가는 것 : 위치·객실수·규모 / 발주처·시공사·설계사 / 공사금액·공사기간 / 핵심요약 / 기사 링크, 그리고 **「확인 필요 : 설계사 안 나옴」** 처럼 빈 칸을 이름으로 알려 줌
- `분석실패` `수신거부` `관련없음` `동향` 줄은 **메일에 넣지 않음**. 본문 맨 아래 「분석실패 n건은 시트에 남겨 두었습니다」 한 줄로만
- 보낸 줄은 탭 맨 끝 **「메일발송일」** 칸에 날짜를 찍음 → 두 번 안 감. 새 현장 0건인 날은 메일 없음
- 같은 사건을 여러 신문이 쓴 것은 제목으로 묶어 「비슷한 기사 n건」 으로 접어 둠. **지우지는 않음** (프로님이 "중복 체크는 내가 하지" 라고 하셨으므로)
- 붙이는 법 : 시트 > 확장 프로그램 > Apps Script > **새 파일**로 붙여넣기 → `setup_현장만메일` 한 번 실행 (매일 07시 확인 트리거가 등록됨)
- **기존에 실패 목록을 보내던 트리거는 제가 지우지 않았습니다.** 트리거 화면(시계 아이콘)에서 프로님이 지우셔야 그 메일이 멈춥니다 (삭제 = C등급 → 사전 확인)

## 새 창이 헷갈리지 않게 (내 메모)

- 현장 찾기의 **본선은 산군**, 구글AI 레이더는 **보조**다. 레이더를 끄자고 먼저 말하지 말 것 — 프로님이 끄라고 하신 건 **0건 메일**이지 레이더가 아니다.
- 뉴스모니터링 시트의 수집·분석 코드는 **아직 안 봤다**(Apps Script 코드는 드라이브에서 못 읽음). 그래서 기존 코드를 고치지 않고 **메일 내는 파일만 따로** 얹었다. 분석실패 861건의 원인(=AI 분석이 왜 실패하는지)은 **아직 안 고쳤다**. 다음에 그 코드를 화면으로 보여 주시면 그때 본다.
- 49번은 클로드를 부르지 않는다. 조사가 필요하면 ★ 줄만 대화에 붙여넣으시는 방식이다(km-00 33번 = 토큰 아끼는 구조).
- 이 세 파일은 GitHub `gamakatu-PM/mic-pm` 브랜치 `claude/mail-notification-cleanup-201335` 에 있다.
