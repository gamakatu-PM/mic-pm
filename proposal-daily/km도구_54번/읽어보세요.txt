KM 도구 54번 - 제안서 PPT (회사 원본 + 현장 내용 합본)

번호를 54번으로 확정합니다. 26번(경로검사)·39번(자가시험)은 이미 쓰고 있었습니다.
제가 세 번 틀렸습니다. 원인을 없애려고 그림 그리는 부분은 번호를 떼고
deck_core.py 로 바꿨습니다. 메뉴 번호를 차지하는 것은 54번 하나뿐입니다.
앞서 드린 26번·39번 zip 은 버리십시오.

무엇이 달라졌나
  청담PJ 제안서(260715, 26장)를 보니 20장이 회사개요·핵심경쟁력·제품·납품실적·A/S 였습니다.
  이 20장은 현장이 바뀌어도 그대로입니다. 다시 그리면 사진과 마감이 원본보다 나빠질 뿐입니다.
  그래서 39번은 이렇게 합니다.

     고정 장 (회사개요·경쟁력·제품·실적·A/S)  ->  회사 원본 pptx 에서 통째로 복사
     현장 장 (표지·운영시나리오·공사한계·요청)  ->  파이썬이 새로 생성

  시험 결과 사진과 표가 그대로 넘어오는 것을 확인했습니다.

준비 (한 번만)
  3_공통사용\원틀\제안서\ 폴더를 만들고 그 안에 회사 제안서 pptx 를 넣어 두십시오.
  청담PJ 제안서처럼 잘 만든 것 몇 개면 충분합니다.
  넣어두면 39번이 알아서 찾습니다. 경로를 입력할 일은 없습니다.

설치
  이 zip 안의 코드\km_tools\ 내용을 2_KM도구\코드\km_tools\ 에 넣습니다.
  들어가는 파일은 t54_deck.py, deck_core.py, 제안서_내용 폴더 3가지입니다.
  기존 파일을 지우거나 덮어쓰지 않습니다.

쓰는 법
  54번_제안서PPT_바로실행.bat 두 번 누르기
  순서대로 이렇게 물어봅니다.
     1) 어느 회사 제안서를 쓸까요           (엔터 = 안 붙이고 현장 내용만)
     2) 어느 장을 고정 장으로 가져올까요    (엔터 = 자동으로 잡은 것 그대로)
     3) 어느 현장 내용을 만들까요           (엔터 = 전부)
     4) 현장명                              (엔터 = 현장명 없는 범용 표준본)

같이 들어 있는 것 : 현장별 한 곳에 보기
========================================

프로님 2026-09-17 말씀 - "폴더가 여기 저기 흩어져 있는 것은 결과값 찾기가 힘드니
생성된 폴더는 몰아서 하나의 폴더에서 볼 수 있게 해. 산출, 견적, 실행, 회의록, 제안서, 단가장."

site_index.py 가 그 화면을 만듭니다.

  파일을 옮기지 않습니다. 폴더도 만들지 않습니다.
  원본은 _도구결과\{도구}\{날짜}\ 에 그대로 있고,
  현장 이름으로 묶어서 보여주고 링크만 겁니다.
  (폴더는 프로님이 정하고 도구가 따라갑니다)

  돌리는 법 : 명령창에서  python site_index.py
  만들어지는 것 : !!클로드가 저장하는 폴더\_현장별_한곳에.html

  화면 : 현장 하나를 누르면 그 현장의 산출·견적·실행·단가장·제안서·회의록·
         의뢰서·일정·돈·도면·사진이 종류별로 펼쳐집니다. 파일을 누르면 그대로 열립니다.
         위 칸에 현장 이름을 치면 걸러집니다.

  33번 현황판에 합치려면 (선택) : t33_dashboard.py 안에 두 줄만
        import site_index
        site_index.build(quiet=True)
  33번 본문은 제가 고치지 않았습니다. 다른 창에서 계속 손보고 계셔서
  제 사본으로 덮으면 최신 작업이 사라집니다.

  현장 이름은 파일 이름 앞머리에서 읽습니다.
  현장명으로 시작하지 않는 파일은 「현장을 못 읽은 파일」로 따로 모입니다.

같이 들어 있는 것 2 : 점유율 정오표 자동 적용 (errata_apply.py)
========================================

청담 제안서에 5성급 점유율이 70% · 70%+ · 75% · 80% 로 섞여 있었습니다.
확정하신 「해외스펙 제외 80% 이상」 으로 한 번에 고칩니다.

  돌리는 법 : python errata_apply.py "제안서.pptx"
              (인수 없이 누르면 원틀\제안서 폴더의 pptx 를 골라 줍니다)
  결과      : 같은 폴더에 「_점유율80」 이 붙은 새 파일 + 바꾼 곳 목록 csv
              원본은 그대로 있습니다.
  건드리는 것 : 「점유」 「5성급」 「10곳」 이 든 문장의 70% · 75% 만
  안 건드리는 것 : 6시간 · 40년 · 52개 · 500,000실 · 24개 등 다른 숫자 전부
  정오표 엑셀(청담PJ_제안서_정오표_v1_260927.xlsx)에 고칠 자리 6곳과
  확인이 필요한 숫자 3건을 따로 적어 드렸습니다.
