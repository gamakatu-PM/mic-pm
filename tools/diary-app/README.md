# KM 업무일지 — 로컬 Excel 연결

회사 자료는 포함하지 않은 프로그램 코드입니다. 원본 업무일지는 PC의 기존 OneDrive 폴더를 사용합니다.

## Windows

1. 이 폴더를 PC의 기존 `2_KM도구/KM_업무일지` 아래에 저장합니다. 기존 파일이 있으면 덮어쓰지 말고 비교합니다.
2. `업무일지_시작.bat`을 실행합니다. Python 3가 필요하며, openpyxl이 없으면 설치합니다.
3. 실제 업무일지 xlsx 파일을 선택합니다. 먼저 사본으로 저장·재조회 시험을 권장합니다.
4. 현장 탭 → 기록 보기·수정 → 엑셀에 저장.

선택한 파일은 실제로 변경됩니다. 매 수정 전 같은 폴더의 `업무일지_백업`에 전체 사본을 남깁니다. Excel에서 파일을 열어둔 경우 먼저 닫습니다.

## PC의 Codex가 확인할 것

- 기존 업무일지 원본 위치와 사용 중인 회의록 프로그램을 먼저 확인. 새 대장이나 중복 프로그램을 임의 생성하지 않습니다.
- 원본을 Git에 추가하지 않습니다. 업무자료·백업·OneDrive 파일을 커밋하지 않습니다.
- 이 브랜치 전체를 기존 폴더에 덮어쓰지 않습니다. `tools/diary-app` 코드만 가져와 비교합니다.
- 기존 프로그램이 해당 엑셀을 갱신하는지 확인하고, 사본으로 파일 재읽기·편집·백업·다시 열기를 시험합니다.
- 본 프로그램은 선택한 시트의 실제 셀을 수정합니다. 동일 내용을 별도로 복제한 전체/월별/현장별 시트까지 자동 전파하지 않습니다.
- 병합 셀 수정은 해당 병합 영역의 여러 행에 함께 반영되며 편집 화면에 영향 행 수를 표시합니다.

## 기술적 범위

Python 표준 HTTP 서버 + openpyxl, 브라우저 UI. `127.0.0.1`에서만 실행하며 토큰으로 로컬 API 접근을 제한합니다. 외부 업로드·메일·AI 호출은 없습니다.

실행 예: `python server.py --choose`
파일 직접 지정: `python server.py --workbook "경로/1.업무일지.xlsx"`

원본 11열 이름이 일치하는 업무일지는 편집 가능, 나머지 보조 시트는 읽기 전용입니다. 외부 파일 변경은 주기적으로 확인하고 편집 중 충돌은 덮어쓰지 않습니다. OneDrive 두 PC의 동시 편집을 자동 병합하지는 않습니다.

Linux에서 실제 첨부 사본 40개 시트 읽기, 브라우저 편집→xlsx 저장→재조회, 백업, 병합 셀 반영, 오래된 판 저장 거부를 시험했습니다. Windows 배치 실행·파일선택창과 회사 OneDrive는 아직 직접 검증하지 않았습니다.
