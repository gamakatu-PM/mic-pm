# 이 폴더는 「이 저장소로 여는 창」 이 자동으로 읽는 스킬 자리입니다

- 여기에 `스킬이름/SKILL.md` 로 두면 **프로님이 아무것도 안 하셔도** 이 저장소를 여는 새 창이 읽습니다.
- 계정에 올리는 스킬(설정 > 스킬)과는 별개입니다. **둘 다 두는 것이 원칙**입니다(규칙 18 이중 저장).
  - 계정 스킬 : 모든 창에서 보임. 프로님이 `.skill` 파일을 올리셔야 함.
  - 이 폴더  : 이 저장소 창에서만 보임. 제가 커밋하면 끝.
- 고칠 때는 두 곳을 같이 고칩니다. 한쪽만 고치면 새 창이 옛 문장을 읽습니다.
