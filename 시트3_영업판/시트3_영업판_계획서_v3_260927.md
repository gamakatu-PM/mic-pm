# 시트 3번 「영업판」 계획서 v3 (2026-09-27)

> **v3 : 시트 v2 완성.** 실제 산군 캡처 11건(9/14)으로 돌아가고, 설계사 연락처·현장 뉴스 조사(웹검색)가 들어 있다. 바뀐 점은 11·12절.
> 다루는 것은 두 가지뿐 — **① 산군(산업의역군) 쓰는 법 ② 설계사 영업.**
> 기존 시트(26년 회의록·무조건할일·신규 현장 레이더·KM 손바닥·도구 47번 찾아갈곳)와 **섞지 않는다.** 그쪽 파일은 열지도 고치지도 않는다.

## 0. 결론 한 줄
산군은 **「매주 월요일 엑셀 1번 받아서 시트에 붙여넣기」** 하나만 하시면 되고, 시트가 **설계사별로 묶어서 「이번 주 찾아갈 설계사무소」** 를 뽑아 주는 구조로 만든다.

## 2. 핵심 생각 — 산군의 「공사단계」 로 누구를 만날지 가른다
| 산군 공사단계 | 우리가 만날 사람 | 목적 |
|---|---|---|
| 건축허가 전·설계 중·허가 직후 | **설계사무소** | 객실관리를 설계에 넣게 함 (특기시방서·도면 무상 지원) |
| 착공 ~ 골조 | **시공사** (+발주처) | 견적·수주, CB외함 일정 |
| 마감 단계 | 늦음 — 경쟁사 설계가 이미 들어갔을 가능성 | 타사 도면 경쟁 견적(km-drawing-cost 방식) |

→ **설계사 영업 = 「허가·설계 단계」 줄만 모아서 설계사무소 이름으로 묶기.** 이것이 시트 3번의 알맹이다.

## 4. 시트 3번 탭 구성 (안 A)
| 탭 | 하는 일 | 프로님 손 |
|---|---|---|
| 0.자가진단·변경이력 | 붙여넣은 건수 = 현장 탭 건수 검사, 버전·바꾼 것 기록 | 없음 |
| 1.산군_붙여넣기 | 주 1회 받은 엑셀을 **그대로** 붙여넣음 (원본 보존, 날짜 칸만 추가) | **주 1회 붙여넣기** |
| 2.현장 | 중복 제거(주소+건물명), 용도 필터(숙박·기숙사·수련·연수원 등), 연면적 기준 `[ ]` ㎡ 이상, 단계로 「설계사행 / 시공사행」 자동 표시 | 없음 (기준 숫자만 입력칸) |
| 3.설계사 | 설계사무소별 : 걸린 현장 수·가장 최근 허가일·마지막 방문일·다음 방문 예정·담당자·전화 | 담당자·전화만 알게 되면 입력 |
| 4.방문기록 | 날짜·설계사무소·만난 사람·들은 것·다음 약속 (폰에서 구글폼으로 입력 가능) | 다녀온 뒤 한 줄 (또는 PLAUD) |
| 5.이번 주 갈 곳 | 자동 : 설계단계 현장이 있는데 **안 가본 곳 / 방문 후 `[14]`일 지난 곳**, 지역별로 묶어 오전 외근 동선 | 없음 |

- 요율·금액 없음. 숫자는 전부 입력칸 `[ ]` (연면적 기준, 재방문 일수, 대상 용도).
- 회사 원가 자료는 이 시트에 넣지 않는다.
