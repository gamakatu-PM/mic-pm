# 시트 3번 「영업판」 계획서 v1 (2026-09-27)

> **이 문서는 계획만이다. 아직 만들지 않는다.** 프로님이 「한다 / 안 한다」 를 정하신 뒤에만 시트를 만든다.
> 다루는 것은 두 가지뿐 — **① 산군(산업의역군) 쓰는 법 ② 설계사 영업.**
> 기존 시트(26년 회의록·무조건할일·신규 현장 레이더·KM 손바닥·도구 47번 찾아갈곳)와 **섞지 않는다.** 그쪽 파일은 열지도 고치지도 않는다.

---

## 0. 결론 한 줄
산군은 **「매주 월요일 엑셀 1번 받아서 시트에 붙여넣기」** 하나만 하시면 되고, 시트가 **설계사별로 묶어서 「이번 주 찾아갈 설계사무소」** 를 뽑아 주는 구조로 만든다.

---

| 항목 | 내용 | 등급 |
|---|---|---|
| 정식 이름 | 산업의역군 (sankun.com) | 확정 |
| 요금 | 공사DB 월 9만원 / PRO 연간 864,000원 (연결제 20% 할인) | 확정(검색) |
| 엑셀 다운로드 | 현장 주소·건물명·연면적·주용도·허가구분·**시공/설계/감리/건축주**·공사단계·허가일·착공일 | 확정(검색) |
| 다운로드 한도 | **주 1회, 최대 300건** | 확정(검색) |
| 알림 | 키워드·기업·지역 조건 → **이메일·카카오톡** 으로 새 공사정보 | 확정(검색) |

## 2. 핵심 생각 — 산군의 「공사단계」 로 누구를 만날지 가른다
| 산군 공사단계 | 우리가 만날 사람 | 목적 |
|---|---|---|
| 건축허가 전·설계 중·허가 직후 | **설계사무소** | 객실관리를 설계에 넣게 함 (특기시방서·도면 무상 지원) |
| 착공 ~ 골조 | **시공사** (+발주처) | 견적·수주, CB외함 일정 |
| 마감 단계 | 늦음 — 경쟁사 설계가 이미 들어갔을 가능성 | 타사 도면 경쟁 견적(km-drawing-cost 방식) |

→ **설계사 영업 = 「허가·설계 단계」 줄만 모아서 설계사무소 이름으로 묶기.** 이것이 시트 3번의 알맹이다.

## 3. 만드는 방법 3안 (각 안이 잃는 것)
| 안 | 내용 | 잃는 것 |
|---|---|---|
| **A (추천)** 구글시트 3번 단독 | 산군 엑셀 붙여넣기 → 설계사별 자동 집계 → 찾아갈 곳 | 기존 도구 47번(찾아갈곳)과 방문 기록이 따로 논다. 나중에 합칠지 결정 필요 |
| B 산군 알림만 켜기 (시트 없음) | 카톡 알림만 받음, 0원·0분 | 설계사별 누적·방문 기록이 안 남음. 지금처럼 잊힌다 |
| C 기존 KM 손바닥/47번에 합치기 | 한 곳에서 다 봄 | 프로님이 원하신 「별도」 가 깨지고, 섞여서 혼동 — 이번엔 제외 |

## 4. 시트 3번 탭 구성 (안 A)
| 탭 | 하는 일 | 프로님 손 |
|---|---|---|
| 0.자가진단·변경이력 | 붙여넣은 건수 = 현장 탭 건수 검사, 버전·바꾼 것 기록 | 없음 |
| 1.산군_붙여넣기 | 주 1회 받은 엑셀을 **그대로** 붙여넣음 (원본 보존, 날짜 칸만 추가) | **주 1회 붙여넣기** |
| 2.현장 | 중복 제거(주소+건물명), 용도 필터(숙박·기숙사·수련·연수원 등), 연면적 기준 `[ ]` ㎡ 이상, 단계로 「설계사행 / 시공사행」 자동 표시 | 없음 (기준 숫자만 입력칸) |
| 3.설계사 | 설계사무소별 : 걸린 현장 수·가장 최근 허가일·마지막 방문일·다음 방문 예정·담당자·전화 | 담당자·전화만 알게 되면 입력 |
| 4.방문기록 | 날짜·설계사무소·만난 사람·들은 것·다음 약속 (폰에서 구글폼으로 입력 가능) | 다녀온 뒤 한 줄 (또는 PLAUD) |
| 5.이번 주 갈 곳 | 자동 : 설계단계 현장이 있는데 **안 가본 곳 / 방문 후 `[14]`일 지난 곳**, 지역별로 묶어 오전 외근 동선 | 없음 |

- 요율·금액 없음. 숫자는 전부 입력칸 `[ ]` (연면적 기준, 재방문 일수, 대상 용도).
- 회사 원가 자료는 이 시트에 넣지 않는다.

## 5. 산군 쪽에서 프로님이 한 번만 하실 설정 (10분)
1. 알림 조건 : 용도 `[숙박시설 / 기숙사 / 수련시설 / 노유자(실버타운)]`, 연면적 `[1,500]㎡ 이상`, 지역 `[전국 또는 수도권]` → 카카오톡 수신
2. 엑셀 다운로드 조건을 같은 조건으로 저장 → 매주 월요일 300건 한도 안에서 받기
3. 설정 화면 스크린샷 1장을 주시면 조건이 맞는지 제가 확인

## 6. 매주 도는 모습 (프로님 손 1번)
월요일 아침 : 산군 엑셀 받기 → 1번 탭에 붙여넣기 → **끝.**
→ 2번·3번·5번이 자동 갱신 → 「이번 주 갈 설계사무소 n곳」 이 뜬다 → 오전 외근 때 들르고 → 4번에 한 줄.

## 9. 겹침 신고 (기존 것을 없애지 않음 — 0번 목록 36)
- **신규 현장 레이더**(건축HUB, 0원)도 건축허가를 모은다. 산군과 겹치는 부분이 있다. 레이더가 설계사무소 이름까지 주는지는 **미확정**. 이번 계획에서는 **건드리지 않고 따로 둔다.**
- **도구 47번 찾아갈곳**은 「견적 보낸 곳」 방문 관리, 시트 3번은 「아직 견적 전인 설계사」 방문 관리 — 대상이 다르다. 합칠지는 3개월 뒤 판단.
