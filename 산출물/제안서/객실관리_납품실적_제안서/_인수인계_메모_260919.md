## 다음 창이 알아야 할 것
1. **대장이 2021.06 에서 끝난다.** 2021.07 이후(조선호텔 스위트 38실·SK하이닉스 2차 1,116실·타니베이·경복대 기숙사·킨텍스 레지던스·에피소드 남산·광희동1가 등)는 프로님 확인 후 r2 에 넣는다. 확인 전에는 넣지 않았다.
2. 거제 한화리조트 지역을 대장 원문 「경북」 → 「경남」 으로 고쳐 넣었다(B등급, xlsx 변경이력에 기록).
3. 수신·문서번호는 `[ ]` 빈칸. 현장이 정해지면 spec 의 doc.to / doc.no 만 채워 r2.
4. 렌더 검수 : 이 환경은 libreoffice-impress 가 없어 `apt-get install libreoffice-impress fonts-noto-cjk` 뒤에 PDF 변환됨. pdftoppm 없음 → pymupdf 로 렌더.
5. 제안서 은행 시트(드라이브 `제안서 은행 (하루 한 장) v1.1`) B017 상태를 「대기」→「r1 작성 2026-09-19」 로 바꿔야 한다 — 아직 안 바꿈(프로님 시트라 C등급으로 봄).
6. km-proposal 스킬에 「유형 L. 레퍼런스 제안서(5장 : 표지 / 실적 요약 카드 3 / 호텔 16 / 리조트·연수원·해외 16 / 요청)」 를 올릴지 프로님께 A/B/C 로 여쭙는다. 아직 안 올림.
