# 5성급 레퍼런스 · 제품 제안서 r1 — 새 창을 위한 내 메모 (2026-09-19)

## 프로님 지시 원문
「레퍼런스를 사진과 어떤 제품을 넣었는지를 건축주한테 가까이 현장을 설명할 수 있는 제안서가 필요하고,
발주처로는 이렇게 다양한 제품을 소개하여 발주처는 어떤 스타일로 해달라고 만족할 만한 답을 들을 수 있게
레퍼런스를 구성해줘. 레퍼런스는 5성급 호텔 위주로 할 것이고 적어도 10군데 이상 할 거야.」

## 이 문서가 앞 문서와 다른 점 (혼동 금지)
- `산출물/제안서/객실관리_납품실적_제안서/` = **r1 숫자형**. 누적 1,598현장·196,441실을 표로만 보여주는 5장.
- 이 폴더 = **5성급 사진·제품형**. 발주처가 **스타일을 고르고 회신**하게 만드는 14장. 두 문서는 용도가 다르니 하나로 합치지 말 것.

## 14장 구성 (이 골격을 새로 상상하지 말 것)
표지 / 제안 요약 / 5성급 실적 1·2 / 객실 어디에 무엇이 / 스타일 1안·2안 대표컷 /
2000 시리즈 전 품목 보드 / 800 시리즈 전 품목 보드 / 계열 4종 표 / CB 마감 3안 / 시스템 3단 /
5성급 표준 구성 / **회신란(빈칸)** / 협의 요청

핵심은 **13장 회신란**이다. 프로님이 원하신 「발주처가 나는 이런 스타일로 해달라고 답하게」가 그 장이다.
회신칸은 절대 채우지 말 것 — 채우면 통보가 되고 답이 오지 않는다(km-proposal §7.4).

## 못 한 것 · 다음 창이 이어서 할 것
1. **객실 전경 사진이 없다.** 드라이브 `실적카다록(2019).pdf`(75MB)·`한국마이크로닉_카탈로그 지명원 실적 통합본.pdf`(98MB)·`한국마이크로닉_회사소개.pptx`(33MB)에 현장 사진이 있는데 **Drive MCP 10MB 제한**으로 못 받았다. 프로님 PC에 있으면 그 사진으로 r2를 내면 훨씬 강해진다.
2. **10000 시리즈(알루미늄)·나이트테이블 사진이 없다.** 표에는 사양만 넣었다. 사진이 생기면 스타일을 2안 → 4안으로 늘린다.
3. 2021.07 이후 5성급 실적(조선호텔 스위트 38실 등)은 대장에 없어 미수록.
4. 「5성급」 등급은 한국관광공사 기준이며 납품 당시 등급과 다를 수 있다. 프로님 확인 후 각주를 넣을지 결정.
