카톡 비서 설치 — 30분

2026-09-19 · 카카오톡 채널 + 오픈빌더 + 구글 Apps Script
끝나면 카톡 친구 목록에 「KM 비서」가 생기고, 거기에 3 완료 치시면 저에게 옵니다.

다 되면 이렇게 됩니다

3 완료
접수했습니다. KM-003 → 완료 대장에 반영하고 결과는 아침 한 장에 올려 드리겠습니다.
할일
오늘 할 것 3건입니다. 1 연합기숙사 타공도 재송부 (오늘까지) 2 도어락 자재승인원 파일 송부 (오늘까지) 3 CB외함 회신 — 시공사 (오늘까지)
「할일」은 제가 미리 채워 둔 답이라 즉시 나옵니다. 메일을 안 여셔도 카톡에서 오늘 할 일을 보실 수 있습니다.

순서 — 넷뿐입니다

5분1카카오톡 채널 만들기
  • center-pf.kakao.com 접속 → 카카오 계정으로 로그인
  • 새 채널 만들기 → 이름은 「KM 비서」 같이 (나중에 바꿀 수 있습니다)
  • 검색 허용은 꺼 두십시오. 차장님만 쓰실 것이라 남이 찾을 필요가 없습니다
  • 만들어지면 채널 검색용 ID를 적어 두십시오
10분2구글 Apps Script 올리기 — 이게 서버입니다
  • script.google.com → 새 프로젝트
  • 이름을 KM 카톡 비서로
  • 기존 코드를 전부 지우고, 드린 KM_카톡봇.gs 내용을 통째로 붙여넣기
  • 맨 위 var TOKEN = 'km2026change'; 의 km2026change 를 아무도 모르는 글자로 바꾸십시오 (예: bsy0924km)
  • 저장 → 함수 목록에서 설치확인을 고르고 실행 → 권한 허용 (「안전하지 않음」 경고가 나오면 고급 → 이동)
  • 메일이 한 통 오고 구글드라이브에 KM_카톡 시트가 생기면 성공입니다
  • 배포 → 새 배포 → 유형 「웹 앱」
    　실행 사용자 = 나 / 액세스 권한 = 모든 사용자 → 배포
  • 나온 주소를 복사하고 뒤에 ?k=바꾸신TOKEN을 붙이십시오
    　https://script.google.com/macros/s/AKfy.../exec?k=bsy0924km
10분3오픈빌더에서 챗봇 만들고 주소 넣기
  • i.kakao.com → 로그인 → 새 봇 만들기 → 카카오톡 챗봇
  • 왼쪽 스킬 → 생성 → 이름 KM회신 → URL 칸에 2번에서 만든 주소(?k= 붙은 것)를 넣고 저장
  • 왼쪽 시나리오 → 폴백 블록(무슨 말을 해도 걸리는 자리)을 엽니다
  • 파라미터 설정 아래 스킬에서 방금 만든 KM회신을 고릅니다
  • 응답은 「스킬데이터 사용」으로 바꾸십시오 (직접 쓰지 마십시오)
  • 오른쪽 위 배포
  • 설정 → 카카오톡 채널 연결 → 1번에서 만든 채널을 고릅니다
5분4카톡에서 확인
  • 카톡에서 채널 ID로 검색해 친구 추가
  • 채팅방에 도움말이라고 보내 보십시오 → 안내가 나오면 끝났습니다
  • 3 완료도 보내 보십시오 → 「접수했습니다」가 오고, 저에게 메일이 옵니다

제가 할 일

언제제가 하는 것
차장님이 카톡을 보내면KM_카톡 시트와 제 메일함 두 곳에 남습니다. 제가 「카톡 봐」 한마디에 전부 읽어 대장에 반영합니다
아침마다보낼말 시트의 할일 칸을 그날 것으로 채워 둡니다. 차장님이 카톡에 「할일」 치시면 즉시 나옵니다
열쇠말 추가보낼말 시트에 줄만 늘리면 새 열쇠말이 생깁니다. 「조용」 「찾아갈곳」 「이번주」 같은 것을 제가 채워 두겠습니다

미리 말씀드리는 세 가지

하나 · 카카오는 5초 안에 답해야 합니다. 그래서 봇은 「접수했습니다」만 즉시 답하고, 제 진짜 답은 그 다음에 나옵니다. 「할일」처럼 제가 미리 채워 둔 것만 즉시 나옵니다.
둘 · 배포 주소는 공개 주소입니다. 그래서 ?k=TOKEN을 붙였습니다. TOKEN을 꼭 바꾸시고 남에게 보여주지 마십시오. 주소가 새면 그때 TOKEN만 바꿔 다시 배포하면 됩니다.
셋 · 회사 승인이 필요할 수 있습니다. 회사 이름으로 채널을 만드시면 마케팅·홍보 부서와 겹칠 수 있습니다. 개인 이름으로 「KM 비서」처럼 만드시고 검색을 꺼 두시는 게 안전합니다.
