## 왜 두 겹인가

```
06:40  클로드   대장(앞으로할것.csv) → 아침대장_YYMMDD.csv 를 드라이브에 올림
07:00  구글서버  드라이브에서 가장 최근 아침대장을 읽어 메일 3통 발송
```

**07:00 발송은 클로드와 무관합니다.** 클로드가 못 깨어나도 메일은 지난 자료로 그대로 오고,
머리에 「자료가 n일 전 것입니다」 가 붙습니다. 조용히 멈추는 일이 없습니다.
9/19~9/21 처럼 **0통이 되는 사고를 막는 것이 이 구조의 목적**입니다.

## 설치 (처음 한 번, 3분)

1. `script.google.com` 접속 → **새 프로젝트**
2. 이름을 `KM 아침메일` 로 바꾸기
3. `Code.gs` 안의 내용을 전부 지우고 **`KM_아침메일.gs` 내용을 통째로 붙여넣기** → 저장
4. 위쪽 함수 선택창에서 **`setup`** 고르고 **실행**
   - 권한 창이 뜨면 : 고급 → `KM 아침메일(안전하지 않음)` 으로 이동 → 허용
   - Gmail·드라이브 권한이 필요합니다. 차장님 계정 안에서만 돕니다
5. 함수 선택창에서 **`testSendNow`** 실행 → 지금 바로 3통이 오는지 확인
6. 끝. 이후 평일 07:00 자동

### 확인용 함수
- `dryRun()` — 보내지 않고 「어떤 대장을 쓰는지 / 며칠 전 것인지」만 확인
- `testSendNow()` — 요일·시각 무시하고 지금 3통 발송
- `installTrigger()` — 시각을 바꾼 뒤 다시 실행 (`KM.HOUR` 수정)
