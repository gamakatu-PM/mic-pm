[번호로 쓸 때] 시작.py 를 누르고 번호를 고르시면 됩니다.

[결과 파일을 못 찾으실 때]
  97 을 누르십시오. 방금 만든 결과가 화면에 바로 뜹니다.
  그 화면 맨 위에 「만든 파일」 목록이 있고, 누르면 엑셀·폴더가 열립니다.

[27번 도면 수량 뽑기]
  * 도면을 먼저 읽고, 그 다음에만 물어봅니다. 한 장도 못 읽으면 아무것도 묻지 않습니다.
  * 현장명은 폴더/파일 이름에서 짐작해 내밀므로 엔터만 누르시면 됩니다.
  * 성급/객실수/층수는 현장대장.csv 에 있으면 묻지 않습니다.
  * 도면에 「기호/내용/수량」 NOTE(범례) 표가 있으면 세지 않고 그 표를 그대로 옮깁니다.
    이게 가장 정확합니다. 세는 것(블록)은 표가 없을 때만 씁니다.
  * 「글자 나온 횟수」는 수량이 아닙니다. 참고로만 보여주고 채택하지 않습니다.
  * xref(외부참조) DWG 는 본 도면이 아니라 건너뜁니다.
  도면 넣는 곳 : 3_공통사용\도면\_여기에_넣으십시오\
  DXF 가 가장 정확합니다. DWG 는 캐드에서 「다른 이름으로 저장 -> DXF」 한 번만.
  PDF 는 글자가 살아 있으면 셉니다. 사진/캡처는 클로드에게 주셔야 합니다.
  기호가 다르면 3_공통사용\도면\기호사전.csv 에 한 줄 추가하시면 됩니다.
  수량은 제가 정하지 않습니다. 블록기준/글자기준을 나란히 보여드립니다.

[28번 단가 붙이기]
  3_공통사용\단가장\ 에 단가장 파일을 한 번만 넣으십시오 (엑셀 그대로 됩니다).
  이름에 「단가장」이나 「CB모듈」이 들어가면 스스로 찾습니다.
  28번이 만들어 주는 파일 3개는 프로님이 고치는 것입니다
    배수.csv    계약/견적/예산 배수와 조립비율 - 제가 정하지 않습니다
    CB구성.csv  CB 1대당 내부 모듈과 수량 (광희동1가 배선도 판독분이 기본)
    별칭.csv    도면 품목명 -> 단가장 이름 연결. 안 맞는 것만 한 줄 추가
  후보가 2개 이상이면 금액을 비웁니다. 잘못된 금액을 내놓지 않기 위함입니다.

[29번 단가장 채우기]
  배선도를 3_공통사용\도면\ 에 넣고 29번을 누르면
    1) 배선도에서 CB 내부 모듈을 뽑고
    2) 단가장에 없는 모듈을 찾아내고
    3) 단가장 새 버전(vN+1)을 만들어 그 모듈을 주황색 줄로 넣습니다
       실행가 칸은 비워 둡니다. 견적가·예산가는 배수 수식으로 채워 둡니다
  * 원본 단가장은 절대 덮어쓰지 않습니다. 항상 새 버전으로 냅니다.
  * 단가(금액) 자체는 파이썬이 만들 수 없습니다. 프로님이 넣으시는 값입니다.
  * 모듈이 아닌 커넥터 이름(DIMMER1, SCOM1~4 등)은 모듈무시.csv 로 뺍니다.

[30번 완성품 만들기]  <- 순서를 모르시면 이것만 누르십시오
  27 -> 28 -> 29 결과를 모아 「다 됐는지」 점검하고, 빈 곳만 모아
  「_클로드부탁서_현장명.md」 한 장을 만듭니다.
  그 파일 하나만 클로드 대화창에 끌어다 넣으시면 됩니다.

  클로드 답(csv)을 3_공통사용\단가장\받은답\ 에 넣고 30번을 다시 누르면
    단가장(새 버전) · 별칭 · 기호사전 · 배수 · CB구성 에 자동 반영합니다.
  그 뒤 28·29번을 한 번 더 돌리면 빈 곳이 줄어듭니다.

  일 순서
    27 도면 수량  ->  28 단가 붙이기  ->  29 단가장 채우기  ->  30 점검/부탁서
       -> (클로드 답 받아 넣기) -> 30 다시 -> 28 다시 -> 12 견적서 원틀에 부어넣기

[현장 도면 보관소 - 31·32번]  <- 도면이 오면 이것만 기억하십시오
  3_공통사용\도면\{현장명}\  폴더를 만들고 캐드·PDF·수량표를 그냥 넣습니다.
  32번을 누르면 현장을 고르고, 31->27->28->29->30 이 묻지 않고 연달아 돕니다.
  31번은 파일 해시로 새 도면을 알아보고 판(r1, r2...)을 매기며,
  이전 판과 품목별 증감(추가/삭제/증/감)을 뽑습니다.  _도면대장.csv 에 기록됩니다.
  파일은 절대 옮기거나 지우지 않습니다.

       -> 이상하면 2) 제대로 검수(라벨 전수·합계 독립 재계산·수량 원본 대조)
       -> 잘못이면 「고쳐도 될까요?」 -> y 면 스스로 고칠 수 있는 것만 새 파일로, 나머지는 클로드 부탁서
  정답본과 시트가 하나도 안 닮으면 = 서식 자체가 다름 = 잘못 (오늘 낸 잘못된 파일 2개가 이 경우)


[28 단가 붙이기 -> 실행산출 6시트 + 견적서(고객용)]  (v22)
  28번(또는 32·36번 안에서)이 끝나면 두 파일을 코드가 만듭니다. 클로드가 손으로 그리지 않습니다.
    {현장}_{날짜}_실행산출_v1.xlsx : 정답본(주일능_실행산출_v5_260828 = 프로님 기준) 6시트를 복사해 값만 채움
                                     (v7 은 기준이 아닙니다. 정답본 폴더에 v5 만 두십시오)
    {현장}_{날짜}_견적서_v1.xlsx   : 정답본(광희동1가_견적서_Rev1) 갑지+내역서. 명칭·규격(형번 - 설명)·CB 서브라인·노무 명칭까지
                                     광희동 식 그대로 (2대째 CB 는 「-CB1과 내부 구성 동일」, 갑지 一金 은 한글 금액 글자). 원가는 절대 안 들어가고
                                     견적단가 = 실행단가 x 견적배수(배수.csv). 단가 없는 줄은 노란 빈칸 [단가확인]
  두 정답본 xlsx 를 3_공통사용\원틀\정답본\ 에 넣어 두셔야 합니다 (없으면 만들지 못하고 알립니다).
  둘 다 끝에 37번 검수가 자동으로 돌고 「통과」가 찍혀야 믿으십시오.
  단가장에 없는 값은 선례(정답본 연합기숙사 v5 에 적힌 숫자)를 넣어 두고 노란칸으로 둡니다 (v24).
    예) 외함 98,400 / 약전 30,000 / 취부 30,000 / 시운전 20,000. 확정하시면 그대로, 아니면 숫자만 고치십시오.
  후보가 여럿이라도 값이 전부 같으면 채택합니다 (퓨즈 1A = 퓨즈 0.5A/5A/10A 전부 50).
  CB 내부 구성(CB구성.csv)도 정답본 연합기숙사 v5 「2.CB 실행」 그대로 만듭니다 (v25). 배선도가 다르면 수량만 고치십시오.
  37번 검수는 노란 빈칸이 하나라도 남아 있으면 「통과」 라고 하지 않고 「이상 - 빈칸 n개」 로 찍습니다 (v25).
  금액 칸 값은 파일 안에 미리 넣습니다 (v26). 인터넷에서 받아 「보호된 보기」 로 열어도, 미리보기로 봐도 숫자가 보입니다.
    PC 에 엑셀이 있으면 엑셀로 한 번 계산해 저장하고, 없으면 파이썬이 계산한 값을 넣습니다. IF 수식 몇 칸은 편집 시작하면 계산됩니다.
