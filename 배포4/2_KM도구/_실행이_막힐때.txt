실행이 막힐 때 (스마트 앱 컨트롤 / 이 앱은 안전하지 않습니다)
================================================================

원인 : 인터넷에서 받은 파일이라 윈도우가 "딱지"를 붙여 막는 것입니다.
       파일이 잘못된 것이 아닙니다.

[1단계] zip 을 먼저 차단 해제하고 다시 푸십시오  <- 이것만으로 대개 해결됩니다
  1) 이미 푼 폴더를 지웁니다
  2) zip 파일 우클릭 -> 속성
  3) 맨 아래 「차단 해제」 체크 -> 적용 -> 확인
  4) 그 다음에 압축 풀기

[2단계] 그래도 막히면 : bat 대신 py 파일을 쓰십시오
  1_설치.py   더블클릭  (처음 한 번만)
  2_시작.py   더블클릭  (매번)
  * 파이썬은 정품 서명이 있어서 보통 막히지 않습니다.

[3단계] 그것도 막히면 : 명령창에서 직접
  1) 이 폴더를 열고, 위 주소창에 cmd 라고 친 뒤 엔터
  2) 아래를 복사해서 붙여넣기

     py -3 -m pip install openpyxl pillow python-pptx
     py -3 코드\km_tools\menu.py

[4단계] 편하게 쓰시려면 : 바탕화면 바로가기를 직접 만드십시오
  바탕화면 우클릭 -> 새로 만들기 -> 바로 가기 -> 아래를 붙여넣기

  py -3 "C:\Users\gamak\OneDrive\26년도 현장\!!클로드가 저장하는 폴더\2_도구모음_25종\코드\km_tools\menu.py"

  이름은 KM 도구모음 -> 마침
  * 직접 만든 바로가기는 딱지가 없어서 막히지 않습니다.

[하지 마십시오] 스마트 앱 컨트롤 끄기
  한 번 끄면 윈도우를 다시 깔기 전에는 다시 켤 수 없습니다.
  위 1~4 단계로 충분합니다.
