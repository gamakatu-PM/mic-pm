   ② 「KM_시트쓰기」 앱스 스크립트 붙이기 + 웹 앱 배포 (5분)
      1) 구글 시트 「26년 회의록2」 열기 → 확장 프로그램 → Apps Script
      2) 왼쪽 + → 스크립트 → 이름 KM_시트쓰기
      3) 산출물\아침메일\KM_시트쓰기.gs 내용 전체를 붙여넣기
      4) 맨 위 var KM_TOKEN = '';  의 따옴표 안에 클로드가 대화창에서 드린 암호를 넣고 저장(Ctrl+S)
         (암호는 메모장에 적지 않습니다 - 저장소가 공개라서)
      5) 위 ▶ 옆 함수 고르기에서 km_selfTest 고르고 ▶ 실행 → 권한 허용(내 계정 → 고급 → 이동 → 허용)
         실행 로그에 「암호 넣음 : 예」 가 나오면 됨
      6) 오른쪽 위 배포 → 새 배포 → 톱니 → 웹 앱
         설명 KM_시트쓰기 v1 / 실행 사용자 : 나 / 액세스 권한 : 모든 사용자 → 배포
      7) 나온 「웹 앱 URL」(…/exec 로 끝남)을 복사해 클로드에게 붙여 주십시오
      ※ 이 주소는 암호와 함께 있어야 움직입니다. 주소만 알아도 아무것도 못 합니다. 지우는 기능은 없습니다.
