KM 도구모음 - 간단 사용법 v2  (2026-09-22)
======================================================
이 한 장만 보시면 됩니다. 자세한 것은 사용법.txt 에 있습니다.


■ 1. 제일 쉬운 법 - 이것만 기억하십시오

   시작.py 를 열고  → 아무 번호도 치지 말고  → 엔터

   이 한 번으로 아래가 전부 저절로 돕니다.
     · 새 판(zip)이 다운로드 폴더에 있으면 갈아끼움
     · 회의록 폴더에 새 회의록이 있으면 구글 드라이브로 올림  (→ 클로드가 읽어 아침 메일에 실음)
     · 도면 폴더에 새 도면이 있으면 현장별로 나누고 수량·금액까지
     · 현황판·아침 한 장을 새로 만듦
   그리고 로그온할 때 + 30분마다 이것이 조용히 혼자 돕니다.
   그러니 평소에는 시작.py 를 열 일도 거의 없습니다.


■ 2. 처음 한 번만

   설치_51번.py 더블클릭  (코드\km_tools 폴더 안)
     → 화면 끝에 「구글 드라이브 폴더 : G:\내 드라이브」 처럼 뜨면 끝
     → 「못 찾았습니다」 가 뜨면 구글 드라이브 데스크톱을 설치해 주십시오 (무료)


■ 3. 이럴 때는 이것  (번호는 화면에서 이름 옆에 있는 것을 치십시오. 번호는 PC 마다 다를 수 있습니다)

   회의하고 왔다            → 하던 대로 회의록 저장만. 나머지는 엔터가 합니다
   도면이 왔다              → 파일명에 [현장명] 넣어  3_공통사용\도면\_여기에_넣으십시오\  에 넣고 엔터
   견적서 만들어야 한다      → 「견적서 채우기」 (수량표 → 원틀)   또는  「단가 붙이기」 (수량표+단가장 → 실행·계약·견적·예산)
   수량이 바뀌었다 (증감)    → 「증감(Rev) 비교」 (수량표 2개 → 증/감)
   오늘 뭐 해야 하나         → 「아침 한 장」  또는  「앞으로 해야 될 것」
   내가 정한 값을 넣겠다     → 「확정 입력·찾기」 (현장 / 항목 / 값 / 근거)
   견적 보낸 데 가봐야 하나  → 「견적 보낸 곳·찾아갈 곳」
   결과 파일이 어디 있지     → 97  (방금 만든 결과가 바로 뜸)
   새 판(zip)을 받았다       → 다운로드 폴더에 두고 엔터  (또는 98)
   뭔가 이상하다             → 「자가진단」 → 화면을 그대로 클로드에게
   다 제대로 돌고 있나       → 「총괄 점검」


■ 4. 화면에 빨간 글자가 나오면

   그 글자를 그대로 복사해서 클로드 대화창에 붙여 주십시오.
   「[오류] 아래 글자를 클로드에게 보여주십시오」 라고 뜨는 것이 그것입니다.


■ 5. 안 하셔도 되는 것

   · 번호 외우기            → 엔터면 됩니다
   · zip 압축 풀기·복사     → 다운로드에 두고 엔터
   · 회의록을 드라이브에 손으로 넣기 → 저장만 하시면 됩니다
   · 아침 메일 보내기       → 07:00 에 저절로 옵니다
