# 산군 + 뉴스 = 영업 카드, 그리고 앱 연결 (v4, 2026-09-19 밤)

v3까지는 「산군에서 찾은 현장을 뉴스로 확인해 메일」 이었습니다. v4는 **두 자료를 합쳐야만 나오는 값**을
만들어 메일 본문에 적고, 같은 내용을 **앱(한국마이크로닉 현장관리)의 영업 파이프라인**에 넣습니다.

## 프로님 말씀 (그대로)
> "산군 데이터와 너의 구글에서 신문 검색하고 데이터를 합치면 아주 멋진 새로운 업그레이드 데이터가
>  나올 것 같아. 그것을 나에게 어떻게 비서로서 효율적으로 알려줄 수 있는지 생각을 해 보고
>  메일로 정리를 잘해서 본문에다가 적어주고, 그다음에 아까 만든 앱으로 연결할 수 있어 보는
>  이것도 앱으로 연결되면 좋을 것 같고. 산군 데이터 엑셀은 클로드 폴더에 저장되어 있어."

## 합치면 새로 생기는 값 (이것이 「업그레이드 데이터」의 실체)

| 자료 | 아는 것 | 모르는 것 |
|---|---|---|
| 산군만 | 허가일·착공일·연면적·설계사·시공사 | 지금 무슨 일이 벌어지는지 |
| 뉴스만 | 착공했다·중단됐다·준공은 언제 | 어느 현장인지·얼마짜리인지 |
| **합치면** | **작업의뢰서를 언제까지 내야 하는가** + 예상 규모 + 하루 동선 | |

1. **역산** — 기사의 「2028년 준공」 + 산군의 착공일로 거꾸로 계산
   기구물 작업의뢰서 / 속판(제어분전함) 작업의뢰서 / 건축에 벽지·페인트 완료 요구 / 기구물 설치 / 시운전·계산서
   + CB외함 작업의뢰서(착공 기준 어림). **프로님 업무의 관문이 작업의뢰서라서 이 한 줄이 핵심입니다.**
   소요일은 km-site-schedule 확정값(시운전 7 · 기구물설치 7 · 빽커버 10 · 기구물제작 50 · 속판제작 60 · 강전접속 30 · 외함제작 14)이고
   `설정.ini [역산]` 에서 고치실 수 있습니다.
2. **예상 규모** — 연면적 → 객실 추정(1실 40~60㎡) → `설정.ini [역산] 실당단가` (**비우면 금액을 안 적습니다**, 규칙 19)
3. **하루 동선** — 같은 시·도의 🔴·🟠 현장을 묶어 「한 번 나가실 때 같이 보실 곳」
4. **오늘 이것만 세 줄** — 메일 맨 위. ①착공한 곳 ②납기가 지났거나 가까운 곳 ③상황을 물어볼 곳

## 메일이 이렇게 바뀝니다 (본문에 다 적습니다)
```
[산군] 빨리 가보실 곳 1곳 · 상황 물어보실 곳 1곳 (2026-09-19)
┌ 오늘 이것만 하십시오
│ ① 조양동 1558-3 — 착공했습니다. (주)파인드건축사사무소 에 오늘 전화하십시오.
│    CB외함 작업의뢰서 — 2027-02-27 (D-161)
│ ② 범방동 1898-7 — CB외함 작업의뢰서 2026-04-15 (이미 157일 지났습니다) 이미 늦었는지 확인하십시오.
│ ③ 부전동 — 상황을 물어보셔야 합니다. 기사에 「중단」
└
한 번 나가실 때 같이 보실 곳 : 강원 1곳 / 부산 1곳
작업의뢰서 납기 — 급한 순서  (표)
현장 카드마다 : 규모·예상금액 · 준공예정 · 언제까지 무엇을(표) · 기사 · 지도·소요시간 · 다음 행동 문안
맨 아래 : 앱에 넣는 법 + 산군_앱카드_YYMMDD.json 첨부
```

## 앱 연결 (index.html — 한국마이크로닉 현장관리)
- 50번이 `산군_앱카드_YYMMDD.json` 을 만들어 **메일에 첨부**합니다.
- 앱 &gt; **영업 파이프라인** &gt; **📡 산군 불러오기** → 파일 고르기(또는 붙여넣기) → 「첫 접촉」 칸에 들어갑니다.
- 카드에 등급 이모지(🔴🟠🟡⚪)·한 줄 요약·연면적/객실·예상금액·가장 급한 납기가 보이고, **자세히 ▸** 를 누르면 전부 펼쳐집니다.
- **이미 있는 현장은 새로 만들지 않습니다.** 산군으로 들어온 카드면 메모만 최신으로 바꾸고, 프로님이 손으로 넣은 현장은 건드리지 않습니다.
- 단계는 전부 「첫 접촉」, 금액은 0 으로 넣습니다. 판단과 금액은 프로님 몫입니다(규칙 19).

### ★ 앱에서 고친 버그 (B등급)
`loadLocal()` 이 **현장(sites)이 하나라도 있어야** 데이터를 불러오게 되어 있었습니다.
그래서 **영업 파이프라인에만 카드가 있으면 새로고침할 때 사라진 것처럼** 보였습니다.
→ 현장이 0개여도 파이프라인·업무일지가 있으면 불러오도록 고쳤습니다.
또 파이프라인 추가·이동·삭제 때 `saveLocal()` 이 빠져 있어 새로고침하면 되돌아가던 것도 고쳤습니다.

## 새 창이 헷갈리지 않게
- 메일은 여전히 **세 통 따로**(산군 / 알리미 / 레이더). 합치지 말 것.
- 역산은 **추정**이다. 메일에도 「추정입니다. 현장에 확인하시고 쓰십시오」 라고 적혀 있다. 확정처럼 말하지 말 것(km-00 1번).
- 실당단가·소요일·소요시간은 전부 프로님 입력칸. 클로드가 채우지 말 것.
- 앱은 `index.html` 하나다(현장관리 v5.7). `km-pm-v5.html` 은 옛 판이라 건드리지 않았다.
- 아직 못 고친 것 : 뉴스모니터링 시트 **분석실패 861건** 원인.

## 추가 (2026-09-19 밤, 프로님 「산군 800건은 다 쓸모가 없어」)

> "산군 데이터 800건은 다 쓸모가 없어. 내가 클로드 폴더에다가 엑셀로 다시 저장해 놓은 게 맞아.
>  한 300건 될 거야."

### 고친 것
1. **파일 찾는 순서** — `클로드 폴더\산군` → `클로드 폴더\5_산출물\산군` → `클로드 폴더` → `_도구결과\산군` → **다운로드(맨 뒤)**.
   다운로드의 800건 원본을 집지 않습니다. 파일이 여럿이면 목록을 보여 주고 고르게 합니다(엔터=1번).
   목록에 어느 폴더에서 온 파일인지 `[클로드 폴더\산군]` 처럼 적어 둡니다.
2. **✕제외를 버리지 않습니다** — `산군_제외후보_YYMMDD.csv` 로 따로 남기고 개수를 보고합니다.
   프로님이 일부러 넣으신 줄이 거기 있으면 기준을 고쳐야 하므로, 조용히 버리지 않습니다.
3. **한 번에 찾는 곳수 제한** — 300곳을 한꺼번에 두드리면 구글이 막습니다.
   `설정.ini [산군메일] 한번에 = 60` (기본). ★최우선 먼저, 그 다음 오래 안 본 것부터.
   못 한 곳은 다음 실행에서 이어집니다. 화면에 「오늘 못 한 n곳은 다음에」 라고 적습니다.
4. **메일이 길어지지 않게** — 🔴🟠🟡 는 카드로 펼치고(`메일에펼칠곳 = 25`),
   ⚪ 흔적 없음·⚫ 이미 끝남·⛔ 검색 못 함은 **한 줄 표**로 접습니다. 전부는 붙임 CSV·앱 카드에 있습니다.
5. **시·도 이름 정리** — 「충청북도 음성군」 → 충북, 「강원특별자치도 속초시」 → 강원. 동선 묶음이 제대로 묶입니다.
