프로님 지시 : *"통합시키는 게 아니라 각각 다 따로따로 만들어야 되지 않냐? 메일도 각각 따로따로."*

| 메일 | 보내는 것 | 빈손일 때 |
|---|---|---|
| `[산군] 빨리 가보실 곳 n곳` | PC 도구 50번 `t50_sangun_trace.py` | 안 보냄 |

### 12.2 0건 메일은 보내지 않는다
2026-09-15~19 닷새 연속 「신규 발견 0건」 메일이 갔다. 프로님 : *"나한테 아무 의미가 없는 거야."*

점검 메일 한 통.

### 12.3 알림 메일에는 정보를 다 적는다
프로님 : *"그 정보는 메일 내용에 다 적어 줘야 돼."*
→ 제목·건수만 적고 본문에 오류 목록을 붙이는 식으로 만들지 말 것. 현장 한 건마다
위치·객실수·규모·발주처·시공사·설계사·공사금액·공사기간·요약·링크를 전부 적고,
**시트에 새 열이 생기면 그것도 자동으로 붙는다.** 빈 항목은 「확인 필요 : 설계사 안 나옴」 처럼

### 12.4 산군 현장 판정 (프로님 정답본과 맞춘 값)
정답본 = 「산군_관심현장 v1 (2026-09-14, 11건)」. 도구 49번이 11/11 일치로 재현한다.
- ★최우선 = 기준의 **2배 이상**(대형) **이면서** 지금 들어갈 때(착공 6개월 이내 또는 착공 전)

- ✕제외 = 객실 용도 아님 / 규모 미달 / 허가 3년 넘도록 착공 기록 없음

### 12.5 흔적 찾기 (50번)
구글 뉴스 RSS(키 없음·0원)로 현장마다 한 번 검색해 기사 제목의 낱말로 가른다.
🔴 착공·기공·시공사 선정 → 지금 가십시오 / 🟠 중단·표류·소송 → 상황을 물어보십시오 /
🟡 협약·심의 → 아직 이름 / ⚪ 기사 없음 → 설계사에 직접 / ⚫ 준공·개관 → 늦음 /
⛔ 검색 막힘 → 대장에 안 적고 다음에 다시 찾는다.
**등급마다 전화·메일 문안을 완성해서 메일에 넣는다**(km-00 3번 : 할 일 나열이 아니라 보낼 문안).

### 12.8 산군 + 뉴스 = 영업 카드, 앱 연결 (2026-09-19 밤, v4)
- **합쳐야 나오는 값**이 이 시스템의 목적이다 : ① 기사의 준공 예정 + 산군 착공일 → **작업의뢰서 역산**(기구물·속판·CB외함) ② 연면적 → 객실 → 실당단가(입력칸) → 예상 규모 ③ 같은 시·도 묶음 = 하루 동선.
- 메일 맨 위는 **「오늘 이것만」 세 줄**이다. 그 아래 동선 → 납기 급한 순서 표 → 현장 카드 → 앱 넣는 법.
- 역산 소요일은 km-site-schedule 확정값이고 `설정.ini [역산]` 입력칸이다. **역산 결과는 추정**이라고 반드시 적는다.
- 앱(index.html, 현장관리 v5.7) **영업 파이프라인 > 📡 산군 불러오기** 로 `산군_앱카드_YYMMDD.json` 을 넣는다. 이미 있는 현장은 안 만들고, 산군 카드면 메모만 갱신, 손으로 넣은 현장은 건드리지 않는다. 단계는 「첫 접촉」, 금액 0.
- 앱 버그 2개 고침(2026-09-19) : ① `loadLocal()` 이 현장 0개면 파이프라인을 안 불러오던 것 ② 파이프라인 추가·이동·삭제에 `saveLocal()` 이 빠져 있던 것.
- 산군 엑셀은 **클로드 폴더 안 `산군` 폴더**(또는 다운로드 폴더)에 두면 49번이 최신 파일을 스스로 집는다.
