# 메일 세 갈래 + 산군 흔적 v2 (v3, 2026-09-19 저녁)

v2(같은 날 오후)에 프로님이 「객관식과 주관식을 다 적용해」 하셔서 50번에 세 가지를 더했습니다.
v1·v2 md 는 그대로 있습니다(지우지 않음).

## 프로님 결정 (2026-09-19 저녁) — 객관식 1·2·3 + 주관식 전부 적용
1. 50번이 기사 **본문까지** 읽는다
2. 산군 메일을 **주 1회 자동**으로 돌린다
3. 지금 이대로 먼저 돌려 본다 (프로님이 하실 것)
- 주관식 : 🔴·🟠 현장에 **지도 링크 + 예상 소요 시간**

## 50번에 더한 것

### ① 본문 읽기 — 「착공」 과 「착공 예정」 을 가른다
- 제목에 착공·중단·준공 같은 낱말이 있는 기사 **최대 2건**만 본문을 읽는다(느려지지 않게).
- 구글 뉴스 링크는 신문사 주소로 풀어서 읽는다. 구글이 바로 신문사로 넘겨 주면 그 페이지를
  그대로 써서 두 번 받지 않는다. 못 풀면 제목만 본다 — 메일에 「(본문 n건 읽음)」 / 「(제목만 봄)」 을 적는다.
- 본문에 **착공 예정·착공을 앞두·연내 착공·착공 계획** 이 있고 **착공했·착공식·기공식·첫 삽** 이 없으면
  🔴 이 아니라 🟡 「착공 전에 도면 협의」 문안으로 내린다.
- 시험 : 제목 「착공 초읽기」 + 본문 「내년 착공 예정」 → 🟡 로 내려감 확인.
- 끄시려면 `설정.ini [산군메일] 본문읽기 = 아니오`

### ② 주 1회 자동 — 50번 메뉴 3번 「등록」
- 작업 스케줄러에 **매주 월요일 07:30** `KM_산군메일_주1회` 가 들어간다. 실행 파일 `2_KM도구\산군메일.py`.
- 그때 하는 일 : 다운로드 폴더의 **최신 산군 파일로 49번을 묻지 않고** 돌리고 → **지금까지 본 ★·△ 현장 전부**를
  7일 주기로 다시 찾아 → 새 흔적이 있으면 메일. 없으면 안 보낸다.
- 프로님은 **산군 파일만 다운로드 폴더에 받아 두시면** 된다. PC 가 꺼져 있으면 그 주는 안 간다.
- 시험 : 이 환경은 리눅스라 `schtasks` 는 못 돌렸다. 35번(아침 메일)과 같은 방식이라 코드는 같다.
  `auto()` 흐름(49 묻지 않고 → 50 전부)은 돌려서 통과.

### ③ 지도 링크 + 예상 소요 시간 (🔴·🟠 현장에만)
- 지도 : 카카오맵·네이버지도 링크(키 없음). `설정.ini [산군메일] 출발지` 를 넣으시면 **카카오맵 길찾기** 링크도 붙는다.
- 소요 시간 두 길 — 둘 다 **프로님이 넣으시는 값**이다. 도구가 숫자를 정하지 않는다(규칙 19).
  - ㉠ `[산군메일] kakao_key` (카카오 REST 키) + `출발지` → 카카오 길찾기 API 로 자동차 시간·km 를 받아 온다.
    **이 길은 시험 못 했다**(이 환경은 카카오에 못 붙는다). 실패하면 조용히 ㉡로 간다.
  - ㉡ `[소요시간]` 표 : 서울= 경기= 강원= … 17칸이 **빈 채로** 만들어진다. 채우신 것만 「대략 2시간 30분 (소요시간표)」 로 적는다.
    비어 있으면 아무것도 안 적는다.
- 시험 : 강원=2시간 30분 을 넣으니 속초 현장에 「가는 길 : 대략 2시간 30분 · 카카오맵 · 네이버지도 · 길찾기」 가 붙음.

### 50번 메뉴 (시작.py 에서 50 누르면)
```
 1) 지금 찾기 (49번 최신 결과)
 2) 지금까지 본 현장 전부 다시 찾기
 3) 주 1회 자동 등록 (매주 월요일 07:30)
 4) 자동 해제
 5) 설정 보기 (설정.ini [산군메일]·[소요시간])
```

## 설정.ini 에 생기는 입력칸 (50번을 한 번 돌리면 저절로 생김)
```

kakao_key =         ; 카카오 developers REST API 키 (넣으면 자동차 소요시간)
본문읽기 = 예

[소요시간]
서울 =
경기 =
강원 =              ; 예) 2시간 30분
… (17개 시·도)
```

## 시험한 것 (통과)
| 시험 | 결과 |
|---|---|
| 본문 풀기 | 구글 링크 → 신문사 주소 → 본문 추출 정상 |
| 「착공 초읽기」 + 본문 「착공 예정」 | 🟡 로 내려감 + 착공 전 협의 문안 |
| 「착공」 + 본문 「착공식을 열고」 | 🔴 유지 |
| 「중단」 본문 읽음 | 🟠 유지, (본문 1건 읽음) 표시 |
| 지도 링크 | 카카오맵·네이버·길찾기 URL 생성 |
| 소요시간표 | 채운 시·도만 적히고 빈 곳은 안 적힘 |
| auto() | 49번 묻지 않고 → 50번 전부 → 메일 1통 |
| 50번 메뉴 | 시작.py 방식(run())으로 부르면 번호 메뉴, 엔터=1 |
