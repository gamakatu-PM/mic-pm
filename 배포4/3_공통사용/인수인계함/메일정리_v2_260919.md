# 메일 세 갈래로 나누기 (v2, 2026-09-19)

v1(같은 날 오전)에서 「0건 메일 중지 + 알리미는 현장만」 까지 했고, v2에서 **산군 흔적 찾기**와
**메일 3통 분리**를 더했습니다. v1을 지우지 않았습니다 — v1 파일도 그대로 있습니다.

## 프로님 말씀 (2026-09-19 오후, 그대로)

> "산군 데이터를 인터넷에서 검색을 해서 흔적을 찾아 가지고 나한테 알려 주는 방식은 안 될까?
>  그 흔적이 찾아지면 내게 빨리 가 보라고. 아니면은 어떤 상황이냐고 이메일로 알려 주는 방식.
>  그거를 알림이는 알림이대로 제대로 된 현장 정보가 메일로 넘어와야 되고 그 정보는 메일 내용에
>  다 적어 줘야 돼. 내가 볼 때는 통합시키는 게 아니라 각각 다 따로따로 만들어야 되지 않냐?
>  그리고 메일도 각각 따로따로 보내야 되고."

## 확정 : 메일은 세 통, 서로 섞지 않는다 (뒤집지 말 것)

| # | 메일 제목 | 누가 보내나 | 언제 | 안 보내는 때 |
|---|---|---|---|---|
| 1 | `[산군] 빨리 가보실 곳 n곳 · 상황 물어보실 곳 m곳` | **PC 50번** (토큰 0) | 49번 돌리신 뒤 (주 1회) | 새로 찾아볼 현장이 없을 때 / 인터넷 검색이 통째로 막힌 날 |
| 2 | `[뉴스모니터링] 새 현장 n건` | **구글시트 스크립트 v2** | 매일 07시 확인 | 새 현장 0건인 날 |
| 3 | `[신규 현장 레이더-구글AI] 확정 n건` | **구글시트 스크립트 v8** | 매일 새벽 | 0건인 날 (7일 연속이면 점검 메일 1회) |

셋을 한 통으로 합치지 않는다. 아침 한 장(35번)에도 끼워 넣지 않는다. 새 창이 "합치면 깔끔한데요"
라고 먼저 말하지 말 것 — 프로님이 따로따로 하라고 명시하셨다.

## 이번에 만든 것

### 50번 `t50_sangun_trace.py` — 산군 현장의 흔적을 인터넷에서 찾는다 (토큰 0, 키 없음)
- 49번이 낸 `산군_새현장_YYMMDD.csv` 를 읽어 현장마다 **구글 뉴스 검색(RSS)** 을 한 번씩 던진다.
  키도 요금도 없다. 클로드·Gemini 안 부른다.
- 검색어는 현장명에서 지번(1558-3 같은 것)과 「신축공사」 를 덜어 내고 시·군·구를 붙여 만든다.
  예) `조양동 1558-3 생활숙박시설` + `강원 속초시` → **`조양동 생활숙박시설 속초시`**
- 기사 제목에 있는 낱말로 등급을 매긴다

| 등급 | 잡는 낱말 | 메일에 나가는 다음 행동 |
|---|---|---|
| 🔴 지금 가십시오 | 착공·기공·첫 삽·시공사 선정·도급계약·실시설계·골조·터파기 | 시공사(없으면 설계사)에 **전화 문안까지** 적어서 |
| 🟠 상황을 물어보십시오 | 중단·표류·무산·취소·소송·유찰·연기·공매·부도 | "지금 어떤 상황인지 여쭙고 싶습니다" 문안 |
| 🟡 아직 이릅니다 | 협약·MOU·추진·계획·심의·유치·공모·투자 | 설계사에 시방서·심볼 미리 드리는 문안 |
| ⚪ 흔적 없음 | 기사 0건 | 설계사·구청 건축과에 직접 물어볼 문안 |
| ⚫ 이미 끝남 | 준공·개관·오픈·개장 | 신축은 늦음 → 교체·증축 영업으로 |
| ⛔ 검색 못 함 | (회사망이 막음) | 집·휴대폰에서 다시 돌리기. **대장에 안 적어서 다음에 다시 찾는다** |

- 메일 본문에 **산군 정보 전부**(소재지·단계·허가일·착공일·연면적·객실추정·설계·시공·건축주) +
  **찾은 기사 최대 5건**(제목·날짜·언론사·링크) + 한 줄 판단 + 다음 행동 문안이 다 들어간다.
- 한 번 찾아본 현장은 **7일 뒤에 다시** 찾는다 (`설정.ini [산군메일] 다시찾기일수`).
  대장 : `_도구결과\_대장\산군_흔적.csv`
- 메일 계정은 35번에서 이미 넣으신 `[메일]` 값을 그대로 쓴다. 받는 주소만 다르게 하시려면
  `[산군메일] to = ...`
- 49번 끝에서 **엔터만 치시면 50번으로 이어진다.**

### `뉴스모니터링_현장만_메일_v2.gs` — 시트에 적힌 칸을 하나도 안 빠뜨린다
- v1이 하던 것(실패·동향·수신거부 빼고 현장만, 재발송 안 함, 0건이면 안 보냄)은 그대로.
- v2 추가 : 그 줄의 **모든 열**을 본문에 적는다. 아는 열(위치·객실수·발주처·시공사·설계사·금액·기간)을
  먼저 놓고, 나머지는 「그 밖에 적혀 있는 것」 으로 전부 붙인다. **시트에 열을 새로 만드셔도 따라간다.**
- 시험 : 가짜 시트에 `착공예정`·`감리`·`비고` 열을 넣었더니 셋 다 메일에 나왔다.

## 프로님이 하실 것

1. 산군에서 관심현장 내려받기 → **49번** → 엔터 → **50번**이 흔적까지 찾아 메일 한 통
2. 뉴스모니터링 시트 Apps Script → **v2** 새 파일로 붙여넣기 → `setup_현장만메일` 실행 → **기존 메일 트리거 삭제**

## 새 창이 헷갈리지 않게 (내 메모)

- 메일 3통은 **일부러** 나눈 것이다. 합치자는 말을 먼저 꺼내지 말 것.
- 50번의 검색은 구글 뉴스 RSS다. **키가 없어야 한다** — 유료 API(네이버 검색·Gemini)로 바꾸자는 제안을
  먼저 하지 말 것. 회사망이 막으면 집에서 돌리시는 쪽이 먼저다.
- 아직 못 고친 것 : 뉴스모니터링 시트의 **분석실패 861건 원인**. Apps Script 원본을 못 봤다.
- 50번은 기사 제목만 본다(RSS라 본문이 없다). 본문까지 읽자면 크롤링이 필요한데 그건 안 만들었다.
