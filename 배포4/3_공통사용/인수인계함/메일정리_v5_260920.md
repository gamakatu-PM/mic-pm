# 산군 메일 서식 v3 (2026-09-20)

프로님 말씀 그대로 :
> "지금 만든 게 넘버 원이라고 하면 가독성을 높인 넘버 2를 만들어."
> "1단계와 2단계를 비교해 가지고 장단점을 비교해 봐."
> **"스크롤이 길고 그런 거는 단점이 아니야. 난 장단점을 보고 개선해서. 넌 V3를 만들어."**

→ **길이는 단점으로 치지 않았습니다.** v2 의 진짜 단점 세 가지만 고쳤습니다.

## v1 · v2 의 진짜 단점 세 가지와 v3 의 처리

| # | v2 의 단점 | v3 에서 한 것 |
|---|---|---|
| ① | **용량 73KB** — 지메일은 102KB 가 넘으면 「메시지 전체 보기」 로 접습니다. 현장이 20곳만 넘어도 잘립니다. | 같은 서식을 줄마다 반복해 적던 것을 `<style>` 한 곳에 모았습니다 → **53KB (-27%)**. 현장 30곳까지 안 잘립니다. |
| ② | **PC 에서 화면이 놀았다** — 폭이 680px 로 묶여 있었습니다. | 폭 **920px**, 카드 속 「어디·규모·예상·때·설계·시공·건축주」 를 **표 2열**(이름/값)로. PC 1200px 기준 카드 한 장 859px → **816px**. |
| ③ | **훑어보기가 느렸다** — v1 은 표라서 한눈에 들어왔는데 v2 는 카드를 계속 내려야 어디에 뭐가 있는지 알았습니다. | 맨 위에 **「한눈에 보기」 번호 목록**(번호·현장명·소재지·가장 급한 것). 아래 카드에 **같은 번호**가 붙습니다. ①③번을 찾으시려면 번호만 보시면 됩니다. |

## 잰 값 (현장 12곳 · 같은 자료 · 크롬)

| | 용량 | 휴대폰 390px | PC 1200px | 카드 한 장(PC) | 한눈 목록 |
|---|---|---|---|---|---|
| v1 (표) | 53KB | 12,109px | 6,791px | 표라서 없음 | 표 자체가 목록 |
| v2 (카드) | 73KB | 18,210px | 15,016px | 859px | 없음 |
| **v3** | **53KB** | **17,910px** | **14,297px** | **816px** | **있음** |

v3 는 **한눈 목록을 더 넣고도** v2 보다 짧고 20KB 가볍습니다.
v1 이 가장 짧지만 현장 한 곳당 적히는 정보가 v2·v3 의 1/3 이라 비교 대상이 아닙니다.

## v3 에서 하지 않은 것 (일부러)
- 현장 수를 줄이지 않았습니다. 25곳까지 카드로 다 펴고 그 다음부터 붙임 파일입니다(`설정.ini 메일에펼칠곳`).
- 카드 안의 항목을 빼지 않았습니다. 「정보는 메일 본문에 다 적는다」(규칙 12.3) 가 우선입니다.
- PC 에서 카드를 2열로 늘어놓는 것은 **안 했습니다.** 지메일이 두 칸 표를 휴대폰에서 안 접는 경우가 있어
  휴대폰에서 글자가 깨질 위험이 있습니다. 한 줄 서식 그대로 둡니다.

## 서식 고르는 법
`설정.ini` → `[산군메일]` → `서식 = v3`(기본) / `v2` / `v1`
- 어제 v2 로 깔린 PC 는 **한 번만 자동으로 v3 로 올라갑니다**(`서식v3올림 = 예` 표시가 남습니다).
  다시 `v2` 나 `v1` 로 적으시면 그대로 둡니다.

## 고친 것
- v3 카드에서 「이 등급의 나머지 n곳」 숫자가 틀리게 나오던 것(항상 전체 수를 적었습니다) → 남은 수로 고쳤습니다.
