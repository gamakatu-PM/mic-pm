## 12. 현장 찾기의 본선은 산군이다 (2026-09-19 확정)

건축HUB 레이더·구글AI 레이더는 **보조**다. 프로님이 산군(sankun.com)을 쓰기 시작하면서
현장 목록은 산군이 준다. 클로드·Gemini 는 목록을 만들지 않는다.

### 12.1 메일은 세 통, 절대 합치지 않는다
프로님 지시 : *"통합시키는 게 아니라 각각 다 따로따로 만들어야 되지 않냐? 메일도 각각 따로따로."*

| 메일 | 보내는 것 | 빈손일 때 |
|---|---|---|
| `[산군] 빨리 가보실 곳 n곳` | PC 도구 50번 `t50_sangun_trace.py` | 안 보냄 |
| `[뉴스모니터링] 새 현장 n건` | 시트 스크립트 `뉴스모니터링_현장만_메일_v2.gs` | 안 보냄 |
| `[신규 현장 레이더-구글AI] 확정 n건` | 시트 스크립트 `레이더_메일_v8.gs` | 안 보냄 (7일 연속 0건일 때 점검 1회) |

「합치면 깔끔합니다」 를 먼저 제안하지 말 것. 아침 한 장(35번)에도 끼워 넣지 않는다.

### 12.2 0건 메일은 보내지 않는다
2026-09-15~19 닷새 연속 「신규 발견 0건」 메일이 갔다. 프로님 : *"나한테 아무 의미가 없는 거야."*
→ 모든 알림은 **내용이 있을 때만** 보낸다. 대신 조용히 죽는 것을 막으려고 연속 0건 7일째에만
점검 메일 한 통.

### 12.3 알림 메일에는 정보를 다 적는다
프로님 : *"그 정보는 메일 내용에 다 적어 줘야 돼."*
→ 제목·건수만 적고 본문에 오류 목록을 붙이는 식으로 만들지 말 것. 현장 한 건마다
위치·객실수·규모·발주처·시공사·설계사·공사금액·공사기간·요약·링크를 전부 적고,
**시트에 새 열이 생기면 그것도 자동으로 붙는다.** 빈 항목은 「확인 필요 : 설계사 안 나옴」 처럼
이름을 불러 준다.

### 12.4 산군 현장 판정 (프로님 정답본과 맞춘 값)
정답본 = 「산군_관심현장 v1 (2026-09-14, 11건)」. 도구 49번이 11/11 일치로 재현한다.
- ★최우선 = 기준의 **2배 이상**(대형) **이면서** 지금 들어갈 때(착공 6개월 이내 또는 착공 전)
- △검토 = 기준은 넘지만 대형이 아니거나, 착공한 지 오래돼 표류 여부를 봐야 하는 것
- ✕제외 = 객실 용도 아님 / 규모 미달 / 허가 3년 넘도록 착공 기록 없음
- 기준값(숙박 1500㎡ · 단독 496㎡ · 클럽하우스 1000㎡ · 그 밖 500㎡ · 착공최근 6개월)은
  **설정.ini [산군] 입력칸**이다. 클로드가 정하지 않는다.

### 12.5 흔적 찾기 (50번)

🟡 협약·심의 → 아직 이름 / ⚪ 기사 없음 → 설계사에 직접 / ⚫ 준공·개관 → 늦음 /
