## 2. ★ 새로 발견한 문제 — 신규 현장 레이더 Gemini API 키가 끊겼다

`gemini-2.5-flash-lite {"code":400,"message":"API key not valid. Please pass a...`
→ 레이더 도구가 쓰는 Gemini API 키가 유효하지 않다(만료·변경·삭제 중 하나로 추정). 코드 문제가 아니라 **키 문제**라서 제가 고칠 수 없다 — 차장님이 새 키를 발급해 환경 비밀에 넣어주셔야 한다. 그전까지는 레이더가 「0건」이 아니라 **「못 찾은 것」**으로 매일 표시된다(원래 설계대로 — 메일 본문에도 그렇게 뜸).
