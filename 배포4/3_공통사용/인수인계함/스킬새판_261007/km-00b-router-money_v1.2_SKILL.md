## 4. 산출물 규격
- 견적서: 회사 원틀(갑지+내역서). 원틀 파일 `원틀_견적서_v1.xlsx`(일반형) / `원틀_견적서_층별_v1.xlsx`(층별형) — **등록 예정, B-4로 만든다.** 정답본 `정답본_견적서_YYMMDD.png` 없음 → 원틀 만든 턴에 묻는다(km-00-router §7-5). 갑지 열너비 절대 변경 금지, TOTAL 십만 절사, NUMBERSTRING 금지(기억 km-quote-automation ★ 원틀 절).
- 실행 산출: 정답본 6시트(0.자가진단/1.입력판/2.CB 실행/3.견적↔실행 대조/4.확인 목록/5.변경 이력) 복사해 값만. 검산 0 필수, 주황 "* 견적가 - 실행" 줄. (2시트 기준은 2026-09-22 폐기 — §8)
- 산출물에는 **수량 등급**(확정 / 도면값 / 추정)이 적혀 있어야 하고, 추정이면 이름 앞 「검토용」 + 견적서 없음. 게이트 판정(출고가능/검토용/미완)을 보고 결론 줄에 쓴다.
- 전달: 원본 xlsx + 드라이브 조회본(값 CSV→구글시트) 세트. 버전은 덮어쓰지 않고 새 번호. 비고에 실행·원가·요율·이윤 문자열 0건(출고 전 전수 검색).

## 5. 절차
### 5-공통 — 새 제품 실행가 전파 (2026-09-02 차장님 원문: "도면 검토를 하다보니 새로운 제품이 나왔어. 그러면 넌 그것의 실행을 위해서 나에게 물어봐야 돼 금액을. 처음에 잘 하더만 이젠 그것도 안 하네. 실행가가 들어가면 단가장, 견적서부터 연결된 총괄 금액이나 대시보드에 저장을 해야 되는 거야")
1. 단가장 조회 실패 품목을 모았다가 **그 턴에 한 번에 묻는다**(§3 문장). 조용히 노란색만 칠하고 넘어가지 않는다.
2. 차장님이 값을 주시면("실행가로 써" = 확정 지시) → ①단가장(CB모듈_단가장 / km-fixture-cost) 등록 → ②견적서·실행표 반영 → ③연결된 총괄 금액·대시보드 갱신. **한 곳만 고치고 끝내지 않는다.** 보고 ①에 세 곳 파일명·셀을 적는다.
3. "모른다"면 노란 [확인]으로 남기고 다음 작업 때 재질문.
### 5-B4 — "견적 원틀 만들어" (2026-09-02 차장님 지시, 새 창에서 실행)
차장님 원문: "1번(광희동1가 260813)으로 하고, 견적서라는 건 언제든지 칸이 늘어날 수도 있고 줄어들 수도 있고, 현장별로 자재가 바뀌면 칸과 줄·금액이 다 바뀌는 거야. 층별로 하는 건 쏘비치 양양 견적서를 기준으로 하면 층별로 나오게 돼 있어." / "나는 지우기만 할 줄 알고 서식(검산·수식)을 넣을 줄은 몰라" → 값 비우기도 서식도 Claude가 한다. 원본을 그대로 받는 게 안전.
1. 드라이브에서 `search_files`로 "광희동" 260813 견적서와 "쏘비치 양양" 견적서 검색("손비치"·"솑비치" 표기도 검색). 못 찾으면 파일명·폴더를 묻는다(추측 금지).
2. 각 파일을 xlsx로 내려받아 openpyxl로 열고: 수량·단가·금액·현장명·날짜·수신처 같은 **값만** 비운다. 수식·서식·병합·열너비·글꼴·소계 구조는 그대로. 갑지 열너비 A 4.43·B 23.57·C 13.86·D 5.43·E 7.71·F 11.57·G 12.43·H 9.43·I 8.86·J~L 13.0 유지.
3. 품목 행이 늘고 줄어도 소계·TOTAL·검산이 따라오게: 소계 SUM 범위를 블록 시작줄~소계 바로 위행으로, TOTAL은 소계들의 합으로(광희동 원본의 49행 SUM 누락 117,131,000원 사고 재발 방지).
4. 「검산」 시트 추가: ①내역서 각 행 수량×단가−금액 ②소계가 블록 전 행을 덮는가(행 수 대조) ③소계 합−TOTAL ④갑지 금액−내역 TOTAL(절사 전) ⑤(수량표가 있을 때) 수량표 합계−견적 수량 합계 ⑥(단가장 연결 시) 단가장 단가−견적 단가. 각 줄 0이면 초록, ≠0이면 빨강(조건부 서식). 맨 아래 「검산 합계 = 0이어야 출고」.
5. 렌더(png)를 보여드리고 승인 → `_원틀/원틀_견적서_v1.xlsx`·`원틀_견적서_층별_v1.xlsx` + `정답본_견적서_YYMMDD.png` 저장(컴퓨터 연결 시 지정 폴더 _원틀이 정본, 드라이브엔 xlsx만·png는 base64 금지) → 이 파일 §4와 km-quote-builder v14 4번 칸에 등록.
6. 승인 전 초안은 원틀이 아니다. 사용량이 크면(파일 2개 다운로드+렌더) 시작 전에 한 줄 고지.
