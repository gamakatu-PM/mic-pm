# 「검토용 표」 서식 v1 — 정답본 xlsx 가 없는 창(클라우드)이 도면·수량표를 받았을 때 내는 것 (2026-10-07)

km-quote-builder v15 §0.0-2 : 클라우드 창은 6시트·견적서를 만들지 않는다. 대신 아래 두 가지만 낸다.
① 28번 입력용 csv (PC 에서 `/도면 --캡처` 가 집는다)
② 이 검토용 표 (프로님이 한눈에 보시고, PC 창이 28번을 돌릴 때 대조한다)

## ① csv — 파일 이름·머리글 고정
`{현장}_도면에적힌수량표_{YYMMDD}_클로드판독.csv` (프로님 수량표를 옮긴 것이면 `_프로님수량표.csv`)
```
기호,내용,수량,쪽,파일,출처
C,입구 INDICATOR,[ ],3,ET-601.pdf,클로드판독·추정
K,KEY SENSOR,[ ],3,ET-601.pdf,클로드판독·추정
CB1,CONTROL BOX 1,120,1,수량표.xlsx,프로님 수량표(확정)
```
- 수량이 안 보이면 `[ ]` 로 비운다. 글자 나온 횟수를 수량으로 쓰지 않는다 (km-00 8번).
- 출처 칸은 세 가지뿐 : `프로님 수량표(확정)` / `도면 NOTE 값` / `클로드판독·추정`.

## ② 검토용 표 — 제목에 「검토용」 과 수량 등급을 먼저 쓴다
```
검토용 · {현장} · 수량 등급 : 추정(평면 심볼 셈) · 2026-10-07 · 견적서 없음 — 수량표 받으면 PC /견적 으로 만듭니다
```
| 구역 | 품목 | 규격(도면 표기 원문) | 수량 | 수량 근거 | 단가장 실행 | 선례 실행(연합기숙사 v5) | 출처·비고 |
|---|---|---|---|---|---|---|---|
| 중앙 | OPERATION PC | OP | 1 | 계통도 NOTE | [ ] | 1,600,000 `[확인]` (MAIN SYSTEM) | 단가장 OPERATION PC 세트가와 구성이 달라 비움 |
| 객실 | CONTROL BOX 1 | CB1 (배선도 없음) | 120 | 프로님 수량표 | [ ] | 356,255 `[확인]` (조립 0.30·외함 98,400) | 배선도 받으면 2.CB 실행으로 확정 |
| 객실 | 입구 INDICATOR | C — CI-2000M(형번 미표기) | [ ] | 평면 심볼 셈(추정) | 31,320 | 18,000 (CI-800S) | 계열 미상 → 2000M 기본 (km-drawing-cost 제-1.1) |
| 노무 | 약전 결선 | 실당 | 120 | = CB 대수 | [ ] | 30,000 `[확인]` | 표준 120,000 과 다름 — 결정대기 45번 |

- **금액 칸을 만들지 않는다.** 실행 총액·견적 3종은 PC 28번이 낸다. 표에는 단가만 적는다 (추정 수량 × 단가 = 추정 총액이 확정처럼 보이는 것을 막기 위해).
- 단가장 실행 = `CB모듈_단가장 v{최신}` 1.모듈총괄 값. 없으면 `[ ]`. 선례 실행 = v15 §선례 사전의 실행단가 칸(H열). 견적단가는 적지 않는다.
- `[확인]` 은 정답본에서도 노란칸이던 값이다. 프로님이 확정하시기 전에는 「선례」 일 뿐이다.
- 아래에 **수량표 요청 메일 본문**(현장명·객실수·필요 도면 종류·캐드+PDF·기한·받으면 며칠 내 무엇을 드리는지)을 붙인다 (km-34 19번).
