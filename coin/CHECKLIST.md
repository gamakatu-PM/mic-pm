# 코인 자동매매 v2 — 운영 체크리스트

각 단계의 □ 가 전부 채워지기 전엔 다음 단계로 가지 않는다. 기간·수량은 차장님이 정한다(빈칸).

## 1단계 설치 (PC, 10분)

- □ 딥코인 → API 관리 → 새 키. 권한은 **거래만** (출금 권한 끔). IP 제한은 걸지 않는다(구글 IP가 바뀜)
- □ Apps Script 새 프로젝트 → `deepcoin-bridge-v2.gs` 내용 전부 붙여넣기 → 저장
- □ 프로젝트 설정 → 스크립트 속성 6개: `DC_API_KEY` `DC_SECRET` `DC_PASSPHRASE` `WEBHOOK_TOKEN` `LIVE=NO` `LOG_SHEET_ID`
- □ 실행 메뉴에서 `SELFCHECK` 실행 → 권한 승인 → 로그 시트 「0.자가진단」 탭이 생기고 **FAIL 0건**
  - 「잔고 조회 (키 유효)」가 OK 면 키·서명·경로가 실제로 맞는 것
  - 「2.설정」 탭이 자동으로 생긴다 → `NOTIFY_EMAIL` 에 내 메일 넣기
- □ 실행 메뉴에서 `설치_일일점검` 1회 실행 → "설치 완료" (매일 07시 자가진단 자동)
- □ 배포 → 새 배포 → 웹 앱 → 실행 계정: 나 / 액세스: **모든 사용자** → 웹앱 URL 복사
- □ 브라우저에서 웹앱 URL 열기 → `{"ok":true,"version":"v2.0 …","live":"NO"}` 보이면 배포 성공

## 2단계 모의 (DRY-RUN) — 기간: ______일 (차장님 결정)

- □ 트레이딩뷰: `pine-alert-wiring.pine` 을 Pine 편집기에 붙여 차트에 올림 → 설정에서 WEBHOOK_TOKEN·ETH 수량·손절% 입력
- □ 알럿 만들기: 조건 = 이 전략 → 「주문 체결 이벤트」, 웹훅 URL = 웹앱 URL, 메시지 칸 = `{{strategy.order.alert_message}}` 한 줄
- □ 「1.거래로그」 상세 열에 `slTriggerPx` 가 값으로 들어 있다 (빈칸이면 손절이 안 실리는 것)
- □ 실행 메뉴 `TEST_모의진입` → 로그 시트 「1.거래로그」에 `DRY-RUN` 행 1개
- □ `TEST_중복차단` → 두 번째 행이 `REJECT DUP`
- □ `TEST_토큰불일치` → `REJECT 토큰 불일치`
- □ 실제 트레이딩뷰 알럿이 도착해 「1.거래로그」에 쌓인다 (모드 열 = DRY)
- □ 기간 동안 「오류」열이 비어 있고, 상태가 DRY-RUN / SKIP / REJECT 뿐이다
- □ 「2.설정」 `KILL` 을 YES 로 바꿔보고 다음 알럿이 `REJECT KILL` 로 찍히는지 확인 → 다시 NO
- □ 「1.거래로그」에 `DUP` 이 연달아 찍히지 않는다 (찍히면 알럿 JSON 의 `id` 자리표시자가 고정된 것 → 고치고 `초기화_중복기록` 실행)

## 3단계 실전 전환 (소액)

- □ 「2.설정」 `MAX_CONTRACTS` = **1**, `MAX_TRADES_PER_DAY` = **2** 로 잠근다
- □ 스크립트 속성 `LIVE` = `YES`
- □ 첫 실주문 후 메일이 온다 → 제목의 `(OK)` 확인. 제목에 `⚠ 주문은 나갔으나` 가 있으면 주문은 나간 것이니 **다시 쏘지 말고** 앱에서 확인. 딥코인 앱에서 포지션 1계약 + **손절이 걸려 있는지** 눈으로 확인
- □ 청산 알럿 후 메일 `(OK)`, 앱에서 포지션 0
- □ 이상 없으면 `MAX_CONTRACTS` 를 원하는 값으로 올린다: ______계약 (차장님 결정)

## 매일 볼 것 (아침 07시 메일 또는 시트 「0.자가진단」)

- 🔴 자가진단 메일이 왔다 = FAIL 이 있다 → 내용 보고 조치. **FAIL 상태로 LIVE 두지 않는다**
- 🔴 「1.거래로그」 상태 열에 `ERROR` 또는 검증 열에 `⚠`/`PARTIAL` → 앱에서 포지션 직접 확인
- 🟡 `REJECT` 가 반복 → 알럿 JSON 이나 상한 설정 문제. 주문은 안 나갔으니 급하지 않음
- 🟢 나머지

## 사고 시 (순서 고정)

1. 「2.설정」 `KILL` = `YES` (폰에서 시트만 열면 됨) → 다음 알럿부터 주문 0
2. 딥코인 앱에서 포지션 직접 정리
3. 「1.거래로그」 마지막 행들 캡처 → Claude 에게 "코인 로그 봐줘"
   - 같은 알럿을 다시 보내도 `DUP` 으로 막힌다. 재실행이 필요하면 `id` 를 새로 붙여 보내거나 `초기화_중복기록` 을 먼저 실행
4. 원인 고친 뒤 `SELFCHECK` FAIL 0 → `KILL` = `NO`

## 되돌리기

- v1 원본은 드라이브 문서 `deepcoin-bridge.gs` 에 그대로 있다. v2 가 문제면 Apps Script 내용을 v1 로 바꾸면 된다(단, v1 결함 3건은 그대로다)
- v1 로그(첫 탭 5열)는 건드리지 않는다. v2 는 「1.거래로그」 새 탭에만 쓴다
